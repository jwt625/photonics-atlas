## Per paper

### caillaud2021 (ECOC 2021, III-V Lab)

Rows: one `photodetector.other` row per diode geometry (D152 InP-native waveguide PD). 4x10 / 4x15 / 5x25 / 5x30 / 5x50 / 6x50 are standard diodes. The 4x10 / 5x25 diodes with a biasing circuit are separate rows because the matching resistor and capacitor make them a different physical design. The facet lens has its own `micro_optics.integrated_lens` row (D396), which carries the Fig. 3 tolerances.

Entered:
- Responsivity at 1550 nm, ref_plane fiber (lensed fiber MFD 5.5 um). Text values use statistic best where the text says "up to" or "to": 4x10 0.6, 6x50 0.91, 5x25 0.8. 4x15 0.73 has no statistic. Each geometry also has an `extracted_from_figure` range row from the Fig. 2 point spread, with n_samples from the figure's count row (8 / 4 / 12 / 10 / 16 / 16).
- 3-dB bandwidths at -1 V and 1 mA on 50 ohm: 70 / 63 / 46 / > 25 GHz from the text. 5x30 (about 41 GHz) and 5x50 (about 29 GHz) are Fig. 4 reads (+/-2 GHz).
- 4x15 bias series (0 / -1 / -2 / -3 V: 45 / 62 / 57 / 53 GHz) and photocurrent series at -2 V (80 GHz at 5 and 6 mA).
- 0.85 A/W at 6 mA. The wavelength is not stated, so the row has c_band inferred and an empty ref_plane.
- S-parameter Rs / C: 27.8 ohm / 16.6 fF, 19.5 / 23.1, 11.5 / 42.8.
- Biased diodes: > 110 GHz at 1 and 3 mA (4x10) and > 86 GHz (5x25). The ">= 120 GHz expected" value is `author_estimate` (D435, extrapolated past the 110 GHz instrument limit).
- Diode W x L as absorber_width / absorber_length (design_target, condition says junction area). Absorber 200 nm `derived` (printed 0.2 um).
- Lens tolerances: lateral 15 um; vertical 2.2 um in `tol_1db_lateral_um` with the axis in condition (D460); longitudinal > 18 um.

Not entered:
- PDL < 0.2 dB (`pdl_db` is not allowed on photodetector). Responsivity variation < 7 % over the C band (no parameter). Dark current "few nA" (no number).
- Bandwidth-efficiency products 34 / 37 / 55 / > 54 GHz (no parameter; `gbp_ghz` is the APD gain-bandwidth product). RC cut-offs and the 80-85 GHz transit-time frequency (notes only).
- Fig. 6 3 mA / 7 mA curves: they overlap the 5 / 6 mA curves at -3 dB.
- Responsivity of the biased samples (not reported separately).
- Earlier-work values in the introduction (rule 3).

Judgment calls:
- 4x15 at -1 V is printed as 63 GHz (Fig. 4 paragraph) and 62 GHz (Fig. 5 paragraph). Both are kept as separate rows with cross-notes (D417).
- Fab is empty. The process is described passively. III-V Lab is in the registry as `org_iii_v_lab`, but no sentence names a fabricator (D80b).
- The lens row has no PD geometry: the paper does not say which diode was scanned in Fig. 3. The lens design is shared by all diodes, so D159 does not apply.

Not entered:

### kurczveil2013 (IEEE Photonics Journal 2013, UCSB)

Rows: 4 `waveguide_platform.transition` rows (rule 10), one per taper design. 4 `waveguide_platform.straight` hybrid waveguide rows, one per Si width and mesa combination, because the mesa differs between Type 1 and Type 2. One passive Si rib waveguide row. Platform is `other` for the hybrid rows (akazawa2026 precedent) and `soi_rib` for the Si row.

Entered:
- Table 2 taper loss, both methods, `derived` (the paper's arithmetic on its own cut-back data), per_component, 1550 nm TE:
  - col. 2: cut-back slope minus hybrid loss.
  - col. 3: L = 0 intercept minus the Si waveguide IL.
- Hybrid loss in dB/mm converted to dB/cm (derived), with condition "additional loss over a Si waveguide".
- Si waveguide fit parameters from Table 3: 5 dB/cm and n_g 3.74 (measured, fit; c_band inferred from the sweep window).
- Geometry: final taper length 80 / 100 um, Si width at the final taper 1000 / 1500 nm (`lower_width_nm`, derived), mesa 24 / 14 um as `width_nm` (derived), 700 nm Si, 400 nm etch, 1 um BOX.

Not entered:
- Taper back reflections, Table 4: -44.0, -41.2 +/- 1.7, -42.8 +/- 1.9, -42.1 +/- 2.0 dB. They are upper limits set by the noise floor, and `back_reflection_db` is not allowed on waveguide_platform. They are in the notes.
- Simulated reflectivity below -55 dB (p.7, no row). Simulated QW confinement 15.6 / 14.4 % (no parameter).
- Hybrid n_g 3.76: one fitted value for all devices (D159).
- About 9.5 dB per facet: a setup term with no coupler row (7 deg angled 2 um Si facets).
- Earlier-work values (refs. [10], [14], rule 3).

Judgment calls:
- Table 2 values are entered per taper. Sec. 3.2 calls the Fig. 5(b) result the "taper (pair) loss", but the abstract, Sec. 3.3 and Sec. 5 state the table range as per taper. My read of the Fig. 5(b) slopes (about 1.7 dB per section for Type 1 - 1.0 um, about 0.67 dB for Type 2 - 1.5 um, minus the hybrid loss) gives about twice the table values per section, which has two tapers. So the table is per taper.
- Table 2 footnotes cite Fig. 6 for Fig. 5 (D417 note).
- Fab is empty: passive "was fabricated" (D80b).

## Registry gaps (skipped values with locators)

1. `pdl_db` on photodetector: caillaud2021 PDL < 0.2 dB for all designs (p.2, p.3). Definition: polarization-dependent responsivity loss, positive dB.
2. `back_reflection_db` on waveguide_platform (transition): kurczveil2013 Table 4, -41.2 to -44.0 dB upper limits (p.10). Definition: back-reflection magnitude of the transition, positive dB, with method and noise floor in condition.
3. `subwavelength_period_nm` and `fill_factor` on mode_converter: yuan2023 SWG period 200 nm, duty cycle 50 % (p.3-4).
4. Switching / actuation energy, e.g. `switching_energy_pj` on splitter / switch_fabric / phase_shifter: her2022 25.8 pJ measured (Fig. 2(d)) and 62 pJ estimated (p.2); D417 lists the same gap.
5. Static hold power on reflector (`tuning_power_mw` widened to reflector, D430 candidate): her2022 SLR.
6. Responsivity flatness over a band, e.g. `responsivity_variation_pct`: caillaud2021 < 7 % over the C band (p.2).
7. Bandwidth-efficiency product, e.g. `bandwidth_efficiency_ghz`: caillaud2021 37 GHz on 50 ohm, 55 GHz on 25 ohm (p.1-3).
8. `rms_roughness_nm` (D432 candidate): golshani2021 < 1.3 nm (p.1).
