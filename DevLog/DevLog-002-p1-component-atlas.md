## Data decisions (D30-D40)

| # | Decision | Rationale |
|---|---|---|
| D30 | Tables in `data/components/`: `components.csv` (one row per physical component design in a source) + `component_metrics.csv` (long: one row per reported value, with its conditions, scope, basis, locator). Schema `data/schema/components.schema.yaml`; per-class parameter registry `data/schema/component_parameters.yaml` (parameter, unit, kind performance/geometry, allowed scope, required conditions, definition). The validator loads both schema files with the registry schema | D1; packaging `metrics.csv` pattern; report section 3 |
| D31 | Class tree: report section 1 (19 rows incl. `wdm`), dotted ids `class.subtype` (e.g. `fiber_chip_coupler.grating`, `wdm.awg`). Single resonators stay `resonator`; a ring used as a channel filter or filter bank is `wdm.mrr` (D2). EO-modulator devices stay in the EO atlas (not duplicated); non-EO phase shifters here | D2, U1 |
| D32 | Row granularity: one component row per physical design; operating points (wavelength, polarization, temperature, bias) and statistics are metric conditions, not new rows. Same-chip siblings with a different design are separate rows. Simulated/design-only components: `row_kind design` | report section 3; EO convention (d)/(z) |
| D33 | Values stored as reported in their natural unit, loss positive in dB (source sign in the note, D3 pitfall 1); linear efficiencies in `%` fields; never convert between 1-dB / 3-dB / FWHM widths; a dB value computed from % is `derived` with the formula in notes | report 2.2 pitfalls 1-3 |
| D34 | `scope` enum for loss (D3): per_coupler, per_facet, per_interface, loopback_half, fiber_to_fiber, on_chip_excess, device_total, de_embedded, unspecified; `includes` / `excludes` free text. Required on loss / insertion-loss parameters | D3 |
| D35 | `basis` enum: measured, simulated, derived, author_estimate, design_target, extracted_from_figure (EO convention (h)/(bb)); `method` enum: cutback, reference_structure, loopback, loss_breakdown, ring_extraction, ofdr, wafer_prober, direct, unspecified. Values the paper cites from earlier work are not entered (pitfall 6) | EO conventions; report 2.2 |
| D36 | Locators: `eo:` sources use the EO convention `p.N` (page of `references/<id>/text.md`) + figure/table; OFC rows (later tranche) `p.~N` (D4). Every metric row carries its locator and basis directly (no separate evidence file); a short verbatim quote (<= 200 chars) is optional and only for open-licence sources | D4, D7; non-OA rule |
| D37 | Bounds/approximations: `qualifier` lt / gt / le / ge / approx (EO convention (b)); ranges as `value` + `value_max` | EO (b), packaging (d) |
| D38 | Links: `source_id` -> registry `sources.csv` (EO papers are `eo:<paper_id>`); `host_device_id` = EO `devices.device_id` when the component is side data of a modulator; `fab_org_ids` -> registry org ids (foundry / cleanroom stated in the paper); `platform` reuses the EO `waveguide_platform` enum plus new values | D5, D8 |
| D39 | Component ids: `cmp_<native source id>_<label>` (ascii slug), immutable; metric ids `<component_id>-m<N>` | D8 style |
| D40 | Distillation is done by subagents under a repo skill (`.claude/skills/pic-component-distill/SKILL.md`) and a batch contract (`data/_staging/components/BATCH_INSTRUCTIONS.md`), staging per batch, merged by `scripts/merge_component_staging.py` after validation; each batch gets a fresh-context audit | EO workflow (DevLog-018/020) |
| D41 | (pilot) `host_device_ids` is a list: every EO device row the component belongs to (all rows of one `physical_device_id`); validated against EO `devices.csv` at merge | pilots diverged (empty vs one representative) |
| D42 | (pilot) `fab_org_ids` = org stated to have fabricated the component (foundry, company, MPW); `facility_org_ids` = shared facility where work was performed / whose use or fabrication support is acknowledged; generic staff thanks and wafer / film suppliers are notes | pilots diverged on acknowledgment-level statements |
| D43 | (pilot) Scope `per_component` for one on-chip component instance isolated from a cascade / reference structure; `loopback_half` for half of a two-coupler measurement; a 1xN / 2x2 value below the ideal split is `excess_loss_db` | pilots diverged (per_coupler vs de_embedded; insertion vs excess) |
| D44 | (pilot) Basis by how a number was obtained: direct (test-structure) measurement `measured`; arithmetic on own measurements `derived`; anything resting on an assumed / cited input or of unstated origin `author_estimate`; datasheet values `specification` (new) | "estimated" wording misled both batches |
| D45 | (pilot) Measurement-setup inputs (test fiber, MFD assumed in simulation, sources, detectors) go in `condition`; setup equipment is never a component row | pilot_2 G9, audit |
| D46 | (pilot) Wavelength: an inferred band carries `wavelength_inferred: true` + reason; nothing stated -> `band: unspecified` + note; a value stated once for several bands is one row | audit (no invented band specificity) |
| D47 | (pilot) Platform = the stack guiding light in this component; new values `lnoi_strip`; EO platform values that look wrong are reported to the EO atlas, not copied | liu2026d / li2025b |
| D48 | (pilot) On-chip inter-layer / inter-material transitions (monolithic or bonded) are `waveguide_platform.transition` with `transition_loss_db` and taper / tip / gap geometry; `chip_chip_coupler` only between separate dies | kohli2025, wu2025 |
| D49 | (pilot) Registry additions: class `reflector`; parameters finesse, linewidth_pm, n_periods, stopband_width_nm, reflectivity_pct, bw3db_khz, heater_resistance_ohm, heater_gap_um, tuning_range_nm, slab_thickness_nm, sidewall_angle_deg; crosstalk_db allowed for wdm (type in condition); statistic `typical`; every component row needs a performance metric (geometry-only items are not rows) | pilot gaps; rejected: PD parameters for setup equipment, rib_height_nm, port_separation_um, generic tolerance |
| D50 | (pilot) Coordinator corrections to subagent output are patch files (`data/_staging/components/<batch>/patch.yaml`, `scripts/patch_component_staging.py`), replayable, each change with its reason | traceability |
| D71 | (contract v3, after batch reports bf_01-bf_06 + ofc_pilot) Registry additions: subtypes fiber_chip_coupler.photonic_wire_bond, laser.tunable, waveguide_platform.slow_light; class frequency_converter; parameters bw_fwhm_nm, bw_10db_nm, slsr_db, kappa_per_cm, linewidth_mhz, tuning_efficiency_pm_per_mw, thermal_time_constant_us, tracking_time_us, rin_integrated_pct, power_consumption_w, power_uniformity_db, wavelength_spread_nm, conversion_efficiency_pct_per_w, poling_period_um; wider allowances (gap_nm chip_chip_coupler; extinction_db amplifier; reflectivity_pct wdm; tuning_power_mw phase_shifter; pitch_um laser / photodetector; il_nonuniformity_db splitter). Rejected for now: facet roughness, il temperature change, rotation error, platform values for dielectric-plasmonic and Si-polymer hybrids (use `other` + core_material) | batch gap reports |
| D72 | (contract v3) fab_org_ids also = the authors' own org when the paper states the authors fabricated it and that org is unambiguous, and the vendor of a purchased device under test; staff / operations-team / training thanks are never facility_org_ids. Ids for non-EO corpora `cmp_<corpus>_<native id>_<label>`. OFC locators `p.~N` / `pNA` always with section or figure | kharel2021 / OFC pilot J1-J3; BRNC inconsistency |
| D73 | (contract v3.1) kappa_intrinsic_mhz, kappa_ext_mhz (resonator, wdm) and mode_splitting_ghz (resonator); linewidth_mhz = loaded full width only. bf_07 rows that stored kappa_0 in linewidth_mhz are repointed in the audit patch | bf_07, bf_10 gap reports |
| D74 | (contract v3.2) extinction_db allowed for splitter (extinction of an interferometer built from it, type in condition) | weigel2018, zhang2026b |
| D75 | (contract v3.3) group_index (waveguide_platform, resonator, wdm), power_coupling_pct (resonator, wdm); bw_3db_nm allowed for waveguide_platform (slow-light passband) | bt_03 |
| D76 | (audit bf_01-03 rulings) On-chip transitions: scope per_component (per_interface stays chip-chip); propagation loss computed from Q (ring_extraction): basis derived, author_estimate when an input (ng) is not stated; photonic-plasmonic / mode converters: insertion_loss_db per_component; D72 applies to universities and institutes as well as companies; supplement pages are cited p.S<N> (page of supplement/text.md); standard fits of the source's own data (Lorentzian Q, S11 fit) are measured, model-parameter extraction with stated assumptions derived; a performance value of unstated design / measured origin is author_estimate (design_target only for dimensions). A convention sweep applies these to all merged batches | audit bf_01-03 (C) |
| D77 | (contract v3.4, ofc_01 gaps) slope_efficiency_w_per_a, repetition_rate_ghz, pulse_width_fs, timing_jitter_fs, pump_threshold_mw, tuning_efficiency_pm_per_v; bw_3db_nm for laser and reflector; capacitance_ff for laser; il_nonuniformity_db for switch_fabric; mfd_chip_um for waveguide_platform. Not added: max tolerated feedback, sweep bandwidth, GDD, lifetime | OFC component papers |
| D80 | (2026-10-20, rulings on the bf_04-12, bt, pk_oi and OFC audit questions) (a) Basis: explicit arithmetic on the source's own measurements (difference of two structures, cascade / N, halving, unit conversion) is `derived` whether the batch or the authors did it; a standard fit of the source's own data (Lorentzian Q, cascade-slope fit, S11 fit) is `measured`; model-parameter extraction with stated assumptions is `derived`; values read off a plot of simulated curves stay `simulated` with the reading uncertainty in notes. (b) D72 needs a statement that the authors (or a named org) fabricated the component ("we fabricate", "our process fab", author contributions): "we developed", passive "fabricated" or all-authors-one-org alone do not qualify; fabricators at two orgs named in the contributions -> both orgs (niels2026, churaev2023). (c) Program / grant acknowledgements (e.g. ARIM "supported ... under Grant") are not facility_org_ids; a named facility thanked "for supporting this work" or for "assistance" is (borderline, noted). (d) Time-aware facility orgs: pre-merger papers that print SNSF / SNF point to those orgs, not to their successor nano@stanford (D27). (e) row_kind `fabricated` when the component exists on the paper's fabricated chip even if only simulated values are reported; `design` only for parts not fabricated. (f) Fiber-only passive parts (fan-outs, MCF isolators / WDM, mode-selective couplers) are in scope; fiber amplifiers and fiber lasers are not. (g) On-chip mirror / reflector couplers between layers of one die are `waveguide_platform.transition`. (h) photodetector.ge_waveguide only when waveguide coupling is stated, otherwise the subtype the text supports or `other`. (i) A value in a sentence carrying a citation is cited work unless the paper clearly reports it as its own result; borderline own-figure cases stay as author_estimate with a note. (j) Self-heating shift per mW of device electrical input goes in tuning_efficiency_pm_per_mw (definition widened). | audits bf_04-06 (C), bf_07-09, bf_10-12, ofc_pilot-09, pk_oi |
| D81 | (contract v4, 2026-10-20) Subtype wdm.other; statistic `std`; parameters avalanche_gain, gbp_ghz, breakdown_voltage_v, saturation_photocurrent_ma, relaxation_oscillation_ghz, fm_efficiency_ghz_per_ma, forward_voltage_v, pump_to_comb_efficiency_pct, beam_divergence_deg, phase_shift_pi, retention_time_s, mech_resonance_khz; class allowances widened: pdl_db (switch_fabric, nonreciprocal), crosstalk_db (fiber_interface, fiber_chip_coupler, chip_chip_coupler), period_nm (laser), radius_um (laser, photodetector), fsr_nm (photodetector), fsr_ghz (laser), n_channels (fiber_chip_coupler, amplifier, nonreciprocal), il_nonuniformity_db (nonreciprocal, fiber_interface), wavelength_spread_nm (fiber_chip_coupler), gap_nm (phase_shifter). Only gaps with a concrete skipped value in a batch report; rejected or deferred: cmrr (system-level), switching energy, comb span, dispersion, bend_loss_db_per_cm (bend rows use prop_loss_db_per_cm with radius in condition, kim2025 precedent), 0.5 / 3 dB tolerances, RSMS slope, lifetime | OFC batch reports, audits |
| D82 | (2026-10-20, rulings on the bt / pk_oi audit questions; amends D76) (a) A performance value stated as the design (designed FSR, design channel spacing, nominal split ratio) is `simulated` when the paper says it was simulated / calculated, otherwise `author_estimate`; `design_target` only for dimensions. (b) Supplement locators: `p.N` (page of the supplement inside text.md) plus `Supp. <label>`, e.g. `p.6 Supp. Note 3, Fig. S1(b)`; this replaces D76's `p.S<N>`, which the `eo:` locator rule (`^p\.[0-9]`) rejects. (c) The owner of a facility named in the facility statement is not itself a facility_org_id (IBM as owner of BRNC). (d) A value that differs from the printed number (unit or prefix conversion, halving, ratio) is `derived`; a value entered as printed keeps its basis. (e) When a component's cross-section is not stated but it comes from the same process as the paper's EO rows, platform = the EO rows' platform with a note. (f) Edge couplers / SSCs: platform = the layer at the fiber-facing facet (e.g. `sion`), the full stack in core_material. (g) Comb repetition rates go in repetition_rate_ghz, line spacing of a non-pulsed comb in channel_spacing_ghz; a 3-dB reflection band of a reflector is bw_3db_nm, stopband_width_nm only for a stated stopband level | audits bt_01-05, pk_oi, ofc_pilot |
| D83 | (2026-10-20, rulings on the convention-sweep and gap-fill questions) (a) Fiber-to-fiber totals keep scope fiber_to_fiber in any class (pk 00229 mirror pair m1/m2). (b) Line spacing of mode-locked lasers and Kerr combs stays channel_spacing_ghz when the paper calls it channel / line spacing and does not characterize pulses (M1B.2, M2A.4, Th2A.46, Th1F.5); repetition_rate_ghz when the paper says repetition rate or characterizes pulses. (c) Fabricators with two affiliations: the org where the fabrication was done (EPFL CMi -> EPFL; cai2025, wang2024a/b). (d) CMC Microsystems providing MPW access is a fab_org_ids role (rule 12 MPW service; geravand2025, Tu2J.5). (e) KNMF named only in funding lists is a program acknowledgement (D80c). (f) Arithmetic on simulated values stays `simulated` (D82d applies to measured / stated values). (g) Gap-fill rows dropped: a bake-stability test of a permanent trim is not a retention time (Th1D.5); static current tuning in pm/mA is not an FM efficiency (M1G.3). (h) Patch replay order per batch: patch.yaml (audit), sweep.yaml (conventions), gapfill.yaml (D81 additions); full order as of 2026-10-22: patch, sweep, gapfill, addendum, geometry, geoaudit, coord, sweep2, coord2, extaudit, sweep3, extaudit2 (files absent in a batch are skipped; DevLog-005, DevLog-007 D255-D256, DevLog-001 D277) | convention sweep, gap-fill |
| D84 | (2026-10-20, rulings on the audit-3 questions) (a) D80b: a statement that the device was made with the authors' own process ("following our previous process", "our process fab") qualifies; naming the platform as "our platform" with passive fabrication steps does not (M4D.5 kept, M1D.4 empty). (b) Thanks to an org's own staff for help with device fabrication place the fabrication at that org: borderline fab_org_ids kept with a note (xie2024 CityU, bhasker2026 Broadcom); still never a facility_org_ids basis (D72). (c) Pulse durations computed by the authors from a sech2 spectral bandwidth enter pulse_width_fs as derived (wang2024b 63 / 71 fs) | audit 3 (sweep + gap-fill) |
