## Coordinator questions (recommendations)

1. ghosh1996 coupling / background loss (judgment (a)). Recommendation: keep as entered. The about 1 dB per interface rests on
   "previous cutback measurements" (p.2) and stays out (rule 3; chen2000 "previous cutback measurement" precedent, lit_53 audit).
   The 0.1 dB/cm is this paper's result (its own 2.4 dB at 1.3 um) with one cited input: rule 4 `author_estimate`, as D429
   (ahmadi2022 net gain on a cited input). Unlike the lit_184 1.2 dB bound it reproduces from the printed numbers:
   (2.4 - 2 x 1) / 5.9 cm = 0.07 dB/cm, printed "about 0.1 dB/cm".
2. ghosh1996 fab (judgment (a)). Recommendation: keep `org_lucent_bell_labs`. The masthead prints "Lucent Technologies, Bell
   Laboratories" (p.1, manuscript Nov 1995, issue April 1996), and the registry holds that lineage id (`org_lucent_bell_labs`,
   historical) separate from AT&T-era `org_bell_labs` (time-correct, D80d / Contract v7: printed historical names stay as printed).
   The basis is rule 12: first person "we have fabricated and tested" (p.2 conclusion) plus all seven authors at that one org; the
   p.3 thanks to one person "for assistance with the device fabrication" is staff thanks, no facility. No existing component row
   uses `org_lucent_bell_labs` yet; no alias row maps the printed string, which is an optional org-round alias, not a missing org.
3. shimizu2024 wavelength span and units (judgment (b)). Recommendation: keep one row per operating point over 1529.16-1619.19 nm
   with the gap note. Rule 7 says one value stated once for several bands is one row, not one row per band; the exact probe edges
   are more informative than `band: unspecified`; Fig. 5 confirms each bound in both bands. The C-input and L-input OPA units are
   two copies of one design (p.3 Fig. 2), so one row (rule 9; abe2025). Splitting into C / L rows would double the 6 rows for no
   new value.
4. shimizu2024 scope (judgment (c)). Recommendation: keep both rows. The OPA is built from the authors' group's own fiber-pigtailed
   PPLN ridge-waveguide modules (refs. [25], [33]), the case the merged shimizu2023 (`amplifier.parametric`, `module`) and
   abe2025 (`frequency_converter.sfg_dfg`, % conversion gain) rows already hold; D642 (fontaine2019) removed a bench assembly of
   purchased bulk parts, which this is not. D396 gives one row per class. Fab and platform empty: no fabrication statement in this
   paper (modules only cited) and no stack (D422, D80b, shimizu2023 precedent).
5. nykolak1993 15 dB (judgment (d)). Recommendation: keep (D408), notes patched. The [4] citation sits on the device sentence ("A
