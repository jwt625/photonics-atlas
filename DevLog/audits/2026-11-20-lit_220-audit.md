## Coordinator questions (recommendations)

1. xu2008 2x2 cross-grid bandwidths 0.09 / 0.19 nm (judgment a). Recommendation: keep. D408: a journal extension of the authors'
   own conference paper keeps its values; D259 / D259a apply only where the value sentence or figure attributes the value to the
   earlier paper. Here only Fig. 5(a) (the SEM panel) carries "[26]" (Xu and Poon, Group IV Photonics 2007, the same 2x2 device), the
   fabrication sentence cites [26-28] as context, and the bandwidth sentence (p.8) and Fig. 5(b)-(d) carry no citation. The radius
   values also appear in the p.7 text, so nothing rests on the SEM panel alone. Storage as bw_3db_nm with "level not stated":
   keep (davis2020 lit_11 Q6, lit_89 bw_3db_ghz with an unlabelled BW); note reworded so it no longer implies the source states a
   3-dB level.
2. xu2008 fabricated crossings Lm 4.3 / 4.5 / 4.7 um with only the simulated Fig. 2(d) point (judgment b). Recommendation: keep all
   three as `fabricated` (D80e: the paper states these Lm values were fabricated, p.5; each Lm is a sibling design, rule 9). The
   Fig. 2(d) reads are correct (simulated at the same Wm / Wt / Lt / Wb, 1550 nm). The Lm 4.5 um row has no described host device;
   dropping it is the alternative but loses nothing wrong. The Wm 1.1 / Lm 4.4 um design stays a separate design row (not fabricated
   at 4.4 um). "~0.4 um" bus width and "~0.35 um" gap stored in nm as `derived` with qualifier approx: keep (D157). Fab
   org_the_hong_kong_university_of_science_and_technology: keep; p.5 is first-person ("We design and fabricate the cross-connect
   filters ... to fabricate the devices") and both authors are at the HKUST Photonic Device Laboratory (p.1), so rule 12 holds
   without D80b's affiliation-only objection. No facility named (HKUST NFF is in the registry but not in the paper). process_name
   empty: "standard silicon CMOS microelectronics fabrication processes" is generic wording (Contract v7).
3. hoffman2019 (judgment c). Recommendations: crosstalk_db for the cross power extinction ratio Pthrough / Pcross: keep (goh2001
   "crosstalk ratio relative to the straight-through transmittance", alexander2024 "crossing extinction ratio" precedents; with
   Pthrough within 0.06-0.18 dB of the input, the ratio and Pin / Pcross differ by < 0.2 dB; the definition is in each condition).
   "total width of 10 um" as length_um: keep (8-fold symmetric shape, so the arm-end to arm-end width is the length; bogaerts2007 /
