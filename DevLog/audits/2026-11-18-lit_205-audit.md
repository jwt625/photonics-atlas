## Coordinator questions (recommendations)

1. pfeiffer2018 version (arXiv v1, title "Probing the loss origins of ultra-smooth Si3N4 integrated photonic waveguides", dated
   2018-02-26). Recommendation: keep with note, no D397 / D409 stop. Same arXiv id 1802.08315 as the source row (its `arxiv_id` links this record to the
   Optica DOI) and the same Damascene reflow study; D397 covers another paper and D409 a correction only. D430 (oser2019,
   wu2023) and D433 (stern2018, qiu2026) accepted preprint texts of the listed works with the journal version unread. Values come only
   from the cached text (rule 1); the component notes already name the version. The registry title stays the journal title.
2. pfeiffer2018 headline on wafer 6, 2 x 0.6 um (judgment (c)). Recommendation: keep, statistic `mean` with `lt` (the paper's words:
   per-ring mean over up to 150 resonances). The Fig. 2(c) vector data confirm the assignment: wafer 6 is the only BHF wafer and its
   2 um markers (34.1-41.0 MHz) are the lowest; the < 35 MHz is met by the best TE and TM 2 um ring, so the values are recorded in the
   m1 notes. Q > 5e6 stays `derived`, ~5 dB/m stays `author_estimate` (n_eff not stated).
3. pfeiffer2018 Fig. 2(c)(d) per-wafer markers and the wafer-3 row (judgments (c), (d)). Recommendation: no per-marker rows. The
   markers are vector and exact (the "dense log-axis" argument does not hold), but each marker is one unnamed ring and the paper prints
   only family statements ("~50 MHz for most wafers", D254). The one printed value tied to an identifiable design (wafer 1, 1.5 um,
   ~100 MHz, p.6) is added as a row (revert = drop the add_components op and its 4 add_metrics). Wafer-3 row: keep the Fig. 2(b) mode
   with empty statistic and the definition in the condition (value corrected to 48 MHz); a later registry statistic `mode` would fit.
4. gundlapalli2022 shared values on all 16 rows (judgment (e), D165). Recommendation: keep. D165 is about one array-level row for
   values regressed over a device family, and D254 forbids a family value on one representative row; here p.3 states the dark
   currents for "all devices" (each sibling row is a design with its own Table II data), the same construction as the merged
   yanikgonul2021 rows (< 0.05 nA on all four APDs, same group). The geometry is printed once for all variants (p.2), so D153 copies
   are correct.
5. gundlapalli2022 absorber_width_um = 0.9 um. Recommendation: keep. Fig. 1(c) draws the intrinsic region (w) in the slab right of the
   core edge (j measured from the right core edge), so light is absorbed in the 0.9 um rib while w sets the junction; yanikgonul2021
   merged rows use the core width too. P_ON / P_SB as power_consumption_w `derived` (nW -> W, D256): keep (registry allows it on
   photodetector; nozaki2016 precedent). GBP `measured`: keep; the gain is neither defined nor printed (p.3), so no explicit
   arithmetic (kang2008, virot2014, tossoun2019 precedent; the merged `derived` GBP rows are author products of
   stated gain and bandwidth).
6. gundlapalli2022 coupler 1.3 dB / end-fire 1.7 dB as this chip's cutback (judgment (f)). Recommendation: keep `measured`, cutback.
   The reference [26] is yanikgonul2021, whose merged values for the 900 nm width are 1.7 dB (edge coupler) and 4.8 dB (end-fire);
   this paper's 1.3 / 1.7 dB differ and its Si layer is etched, not epitaxial (p.2), so [26] is cited for the method only (no D259).

8. cao2021 and rouvie2008 (judgments (a), (b), (g)). Recommendations: cao2021 keep the printed ~2 dB/cm with the Fig. 4(c) note, no
