## Coordinator questions (recommendations)

1. wang2023f measured P_pi ~2.3 mW (judgment 1): enter as `author_estimate` with a D80i note (patched as m8). The paragraph describes
   this work's characterization ("practically inspected using a test structure of a Mach-Zehnder interferometer ... The
   interferometer was deployed ... where the P_pi was measured to be ~2.3 mW"), but the value sentence cites [26]-[29], three of them
   the authors' own. D80i sends exactly this borderline own-figure case to `author_estimate` with a note (rees2020, hwang2007,
   moscosomartir2017); D259 / D408 removal applies where the sentence attributes the value to the earlier paper, which it does not say.
   Alternative (drop m8): defensible if the coordinator reads the citation as attribution.
2. wang2023f loss-breakdown bases (judgment 2): all three breakdown terms that are not printed elsewhere as results (polymer array 1 dB,
   interface 2 dB, emitter 0.5 dB) `author_estimate` (patched m2). The "characterized in a similar manner" sentence names a test but
   prints no result, and the same unprinted test would be the only possible source of the 2 dB interface term too; rule 4, D428, D544.
   The 0.8 dB and 1.2 dB terms stay `measured` / `derived` because p.6 prints them as test results. Rule 10 classes are right: the SiN
   splitter / emitter chips and the polymer chip are separate dies bonded with UV epoxy (p.6), so the interface is
   `chip_chip_coupler.butt` (not `waveguide_platform.transition`), and the fiber-facing SSC is `fiber_chip_coupler.edge`; two rows with
   a D396 cross-note is correct. 1x64 tree kept as its own row with 1.2 dB `derived` (judgment 6; a distinct 1x64 design, printed
   value). Lens-module transmitter values stay out (D411, D558). org_ligentec on SiN rows only (D515 per-part fab) agreed.
3. levy2012 facility (judgment 3): keep empty. The Cornell NanoScale Facility, CNS and NNIN appear only inside the IEEE funding footnote
   "This work was supported in part by ..." next to DARPA, NSF, AFOSR (p.1). D83e, D437 (blaicher2020 KNMF), D611 (yang2018a KNI) and the
   lit_173 luke2013 ruling (Cornell CCMR "supported in part by" = funding line) all treat that construction as a program
   acknowledgement; D80c's borderline clause is for a facility thanked "for supporting this work" or for assistance in an
   acknowledgment. Threshold ~50 mW out (credited to [11], rule 3) agreed. Intrinsic Q ~1e6 `author_estimate` (D403; no extraction
   shown) agreed. 7 dB lensed-fiber loss: keep scope `unspecified` (plural "coupling losses", input lensed fiber and output lens both
   present, p.2) and `measured` (D167 stated value; D462 lensed-fiber precedent); the alternative `author_estimate` (D418 nader2025,
   D437 theurer2019: stated loss not tied to a measurement) is weaker here because the sentence sits in the experiment description.
4. wang2023f SiN reference OPA (judgment 4): keep its own row. Its tip width is not restated (p.6) and its measured 0.4 deg FWHM depends
   on the 64 x 3 um aperture, not on Wtip; assigning it to the Wtip 300 nm row would fix an unstated identity (D159). Interface platform
   `sin` -> `other` (patched; D71 and the merged SiN / Si-to-polymer die couplers); hybrid OPA platform `other` agreed (D71).
5. kourogi1993 0 rows (D411) agreed. lu2008 312 fs (judgment 5): keep `derived`. The 0.707 factor is a pulse-shape deconvolution chosen
   from the authors' own fit to the data (p.4); merged deconvolved autocorrelation widths are `derived` (lo2017 sech2, weng2021 and
   ofc2026 Th1F.6 Gaussian; D80a "model-parameter extraction with stated assumptions"); `author_estimate` would apply only to an
   unsupported or cited shape assumption (hu2022 nominal fiber dispersion). lu2008 fab empty agreed (D80b). NRC alias: see Missing orgs.
