## Coordinator questions (recommendations)

1. herrmann2022 frequency-channel isolation as `isolation_db` (distiller Q1). Recommendation: out, as patched, consistent with
   D581. I_ij has the same form as dostart2020a's |S32|^2 / |S23|^2 (D581); the "perfect filtering" premise that D581 cites is
   here implicit: at the operating point the same-frequency feed-through is 0.19-0.29 (Supp. Eq. (12)), so light at w1 or w3 is
   not suppressed in the reverse direction, and the paper itself proposes adding a filter resonator (p.5). Mirror symmetry (Fig.
   S5) makes I31 a genuine reciprocity-breaking ratio, which is also true of the D419 / D513 cases. Better fix: implement the
   D419 `conversion_contrast_db` on nonreciprocal now and re-file the 4 herrmann2022 values (notes hold value, condition,
   locator) and dostart2020a 13.1 dB; if that lands before the merge, swap the 4 delete ops for parameter changes.
2. "nearly 40 dB" (p.1, p.2, p.6) vs Fig. 2(b) / (c) I31 peak about 35 dB at the same RF powers (distiller Q2). Recommendation:
   the printed value stays the headline with the figure read beside it (D417; oser2019 / D430 precedent). Audit observation, not
   data: the |S13|^2 dip in Fig. 2(b) reaches about -39.5 dB, which may be what "nearly 40 dB" restates; the paper does not say.
3. herrmann2022 `lnos_rib` with no stated etch depth (distiller Q3). Recommendation: keep. D422 / D423 empty a platform the
   paper never states (SOI never named); here LN on sapphire is stated (p.6 Methods) and `lnos_rib` is the only LN-on-sapphire
   enum value (merged precedent eo:didier2026 with unstated film thickness). Registry note: an `lnos_strip` value would be needed
   only if a paper states a fully etched LN-on-sapphire guide.
4. "nano@stanford labs" (p.6) vs `org_nano_stanford` (distiller Q4). Recommendation: add `org_nano_stanford` as facility, as
   patched. The paper prints the registry org's own name with a facility statement ("performed in part in"); D80d only forbids
   re-pointing printed SNSF / SNF to the successor. Aliasing the string to SNSF / SNF would need knowledge from outside the paper.
   Org round: the `org_nano_stanford` record describes it as the 2026 merger successor (2026 news name_source); this 2021 print
   shows the name in use as the NNCI site label (award ECCS-1542152) before that; record the observation (evidence
   `lit:herrmann2022 p.6`), no new org.
5. che2024 fab empty, `process_name` "photonic damascene process (ref. 17)", background loss `author_estimate` (distiller
   judgment). Recommendation: keep all three. Fab: "was fabricated using the photonic damascene process [17]" is passive and names
   no org; authors at Nokia Bell Labs, EPFL and UCF (D80b, Contract v7: named process with no named foundry keeps
   `process_name`, fab empty; merged qiu2026 "photonic damascene" with empty fab). Background loss: the sentence (p.5) has no
   citation and no measurement is shown; D80i borderline own-figure case -> `author_estimate`; the cited "below 3 dB/m" (p.3,
   ref. 17) stays out. Band set to c_band inferred (rule 8, patched).
6. poulvellarie2021 lower bounds, estimates and empty fab (distiller judgment). Recommendation: keep. The paper calls its
   2500 %/(W cm2) a lower bound (all SH assumed collected, p.4) and the 3.8 mW section input rests on the "estimated" 6 dB
   coupling loss (origin not stated), so `gt` + `author_estimate` (rule 4; a smaller true coupling loss would lower kappa_exp, so
   the bound itself depends on the estimate). 6 dB coupling `author_estimate` (D418 nader2025 precedent; D167 not extended to
   "estimated"). Fab: "We fabricate ... [19]" with authors at five unrelated orgs (ULB, Ghent University-IMEC, Angers, Thales,
   C2N): empty (D154 / D395).
7. javid2021 single facet row (distiller judgment). Recommendation: keep. Every SPDC result (bandwidth, pair generation
   efficiency, CAR, visibility) lacks a registry parameter (D250 deferred photon-pair metrics); a converter row with only the 5 mm
   length would be geometry-only (rule 9). The facet row carries the film / etch / BOX geometry.
8. herrmann2022 racetracks 2 / 3 "total loss rate" 198 / 225 MHz as `linewidth_mhz` (not raised by the distiller). In the paper's
   model these bare modes have no waveguide coupling (Supp. Eqs. 1b / 1c), so the total rate is their intrinsic loss, and the
   `linewidth_mhz` definition sends intrinsic loss rates to `kappa_intrinsic_mhz`. Recommendation: keep `linewidth_mhz` (the
   printed quantity is "total loss rate"; the intrinsic reading is a model inference), with the note added on the component
   (patched). Re-file to `kappa_intrinsic_mhz` only if the coordinator reads the model as the paper's own statement.
