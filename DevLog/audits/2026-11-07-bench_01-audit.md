## Rulings requested (points 1-7)

1. fab_org_ids. M1E.4: p.~2 Sec. 3 names the foundry in the fabrication sentence ("fabricated through TowerJazz
   foundry") for the PIC that holds the 4-tap filter; the P_pi test MZI is a bare die of the same work, no second
   fabrication is described. Keep `org_tower_semiconductor` on both rows; alias row TowerJazz needed (as the batch
   report says). alexander2024: p.1 Sec. II says the baseline stack is fabricated in GlobalFoundries' 300 mm foundry;
   GF stays on the four baseline rows (SNSPD, MZI, heater, pump filter, all Sec. II / III). Next-generation rows stay
   empty: p.5 Sec. IV "multiple process flows"; Fig. 1(b) draws Gen2 as SiN + BTO steps added to Gen1 but names no
   site, and p.6 calls the BTO growth a proprietary process. Recommendation: no change.
2. M1E.4 platform. The paper states only a commercial 300 mm silicon photonics platform; heaters sit over "three-folded
   waveguides" with no material; no SOI, BOX or Si-waveguide wording. D423 applies (rizzo2020 precedent, same group).
   Recommendation: platform empty on both rows (patched). Consequence: the 8.8 mW Tower P_pi leaves the tower.siph
   to_ppi cell (the benchmark drops empty-platform rows except the Ge-PD class rule). To keep it, the coordinator would
   need to overrule D423 for this source; drop the platform ops in that case.
3. alexander2024 derived values. Arithmetic correct (above). Scope `per_coupler` is right: the Fig. 5(c) axis is
   insertion loss per edge coupler and the text calls it coupling loss, not a two-facet total; how the per-coupler
   number is separated from the input-output transmission is not stated (method unspecified is correct; if it is a
   plain halving the scope would be `loopback_half`, which the edge_il row also accepts, so no column effect).
   Statistic was wrong-typed (`best` -> `mean`, patched).
4. Temperature. Hairpin SNSPD rows: p.2 Sec. II ties about 2 K to the Fig. 2(e) efficiency measurement: 2 K stated. MZI, heater
   and pump filter: read out with the co-integrated SNSPDs in the packaged system (Fig. 2(c), (d) captions), cryostat
   base about 2 K (p.3 Sec. III); no per-measurement temperature printed. Recommendation: keep temperature_k 2 with the
   existing notes (the readout cannot be at room temperature); removing it would put the cryogenic, figure-read
   about 10 mW heater P_pi into the gf.siph to_ppi cell. SiN waveguide / crossing / splitter / edge-coupler values: no
   temperature stated (room or cryogenic unknown); empty, now said in the notes. PNRD: not stated, cryogenic amplifier
   only (Fig. 4(f)); empty with note.
5. 8.8 mW. Printed as P with subscript pi twice (Fig. 2(b) caption, Sec. 3): per pi; the 1.15 mW trim for 0.13 pi
   checks against 8.8 mW per pi. Wavelength: none stated for the bare-die test (broadband SLD / OSA are the packaged
   setup). C band inferred under rule 8 from the operating band of the same chip (Kerr comb lines 1525.2-1553.9 nm,
   p.~2 Sec. 3, p.~3 Fig. 3); justified, flag true. Recommendation: keep.
6. SiN splitter subtype. The p.6 section heading names directional couplers and crossings; the body and the Fig. 5(b)
   caption say waveguide splitters; p.6 Sec. IV later refers to the "beamsplitter and crossing devices previously
   described". The only splitter type the section names is the directional coupler. Recommendation: keep
   `splitter.directional_coupler` (registry: straight, bent, tunable) with the existing note; `other` is the fallback
   if the coordinator reads the heading as a topic list only. No benchmark effect (no DC row in the table).
7. Misses. None added. Considered: SNSPD dark count rate (`dark_count_rate_hz` exists) only on the Fig. 2(e) log-scale
   inset, no printed value and no single bias; cascaded-source and HSPS metrics (purity, indistinguishability, CAR,
   g2, Klyshko efficiency) have no registry class; BTO phase-shifter values (VpiL 0.62 V cm, 53 dB/m, about 100 mdB,
   0.33 V dB, Pockels > 1000 pm/V) are EO metrics (rule 2); 115 dB system suppression; M1E.4 0.12-0.42 pi MZI phase
   mismatch (no parameter; `phase_error_deg` is 90-degree-hybrid only; registry candidate `phase_imbalance_pi`, D453).
