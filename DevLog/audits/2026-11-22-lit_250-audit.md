## Coordinator questions (recommendations)

1. ai2024 edge-coupler fab (judgment a): keep `org_university_of_maryland_college_park`. The process of Sec. 4.1 is one chip process
   (one EBL write field holds the device and its routing), the inverse tapers are on the same chip, and Sec. 4.3 uses first person for
   the fabricated devices. Same-chip precedents: nielson2005 ring (fab on the same chip), tahara2024 SSC (AIST kept on same-chip rows).
   Contract v7 per-component fab (D515 / D463) is about an org named for one part's process, which is not the case here. Strict
   alternative: empty fab on this one row.
2. ai2024 IL as `excess_loss_db`, `de_embedded`, method `unspecified` (judgment b): keep (D708 paredes2021). The Fig. 11 trace goes
   below 0 dB (to about -0.5 dB), which confirms a normalization to an unnamed reference, not to an absolute input power; Fig. 13 names
   a "reference line" only for the 1310 nm TSL data.
3. ai2024 absolute 1-dB criterion in `bw_1db_nm` (judgment c): keep, criterion in condition and notes (D539 lu2015a precedent;
   registry candidate `criterion_bw_nm`, also asked for mode_converter in D708). The registry definition is relative to the peak, so
   the condition text is load-bearing.
4. ai2024 edge coupler 1450-1640 nm inferred (judgment d): keep. The 3 dB/facet sentence sits in the TSL paragraph and prints no
   wavelength (rule 8); D393 does not apply.
5. guo2023a TE0-TE2 simulated point (judgment e): keep Table 2 / conclusion (0.28 dB / -28.6 dB). Fig. 3(b) render: at 1.55 um CT is
   about -28.5 dB and IL about 0.28 dB; the CT dip (about -33 dB) sits at 1.56 um. The p.7 values (0.27 / -33.7) describe the dip
   "around" 1550 nm; the conflict note is correct. Optional: add the Fig. 3(b) reading to the m6 / m7 notes.
6. guo2023a bands (judgment f): keep. TE1-TE2: CT < -17 dB is the stronger bound over the same 1515-1560 nm band (Table 2 also prints
   "IL < 1.8, CT < -17"). TE0-TE3: Fig. 6(c) shows the TE3 trace between about -1 and -2.5 dB across 1480-1580 nm, so the IL bound may
   hold more widely, but the sentence ties it to 1538-1563 nm; the conservative tie is right.
7. Design rows (judgment g): keep all 12. TE2-TE5 is simulated only (rule 9, design); the five no-SWG-array ablations are different
   structures (arrays removed) with their own printed IL / CT (sibling design rows, rule 9); the chen2015c
   initial three-section design has its own dimensions and value; the three combined converters have printed means. The combined rows'
   composition (TE2-to-TE0 then reversed TE1-to-TE0, etc.) is the distiller's reading of "Combining those devices" (p.6); it is in notes,
   not in data, so no change.
8. chen2015c % / dB pairs (judgment h): keep one `insertion_loss_db` row with the % in notes. Both forms are printed for the same
   quantity, the abstract and conclusion use dB only, and a second `coupling_efficiency_pct` row would double-count the value. Rule 5
   (% kept in % parameters) governs values printed only in %.
9. chen2015c derived lengths (judgment i): keep. Fig. 1 caption defines the total length as L1 + L2 + L3; Fig. 3(a) draws L1, L2, L3
   end to end; Fig. 3(b) L1-L3 run from the input vertices (x = 0) to the output vertices (x = 22711 nm). Locators fixed in the patch.
10. xiao2013 headline values on the Wt 540 nm row (judgment j): keep. "Optimum loss performance ... Wt = 540 nm" (p.6) and the 540 nm
    markers (TE about -0.10, TM about -0.19 dB) match the fitted -0.11 / -0.18 dB; the fit is a standard fit of own data (D80a). Note for
    the record: the printed EL equals slope minus 3.000 dB (3.112 -> 0.11, 3.184 -> 0.18, 3.142 -> 0.14); with 10log2 = 3.010 dB the values
    would be about 0.01 dB lower. Printed values kept; no change.
11. xiao2013 SSC intercepts (judgment k): keep `fiber_to_fiber`, not halved, `measured`. The intercept is at zero splitters, outside the
    port range 1-5, but intercepts of a cascade / cutback fit stay `measured` (lit audit ruling on xu2019c: D435 covers projections past
    an instrument or time limit, not intercepts). Halving would make a `per_facet` `derived` value that still holds the residual
    waveguide loss; the paper says the intercept "mainly" reflects facet coupling.
12. Platforms (judgment l): xiao2013 MMI rows patched to `soi_strip` (see table). xiao2013 SSC: keep `soi`; the etch sentence names
    "the device" and the SSC sentence follows separately, with a two-step etch whose second step the paper does not describe
    (alternative: `soi_strip`, same wafer and etch). guo2023a: keep `soi`; full etch is printed only for the SWG arrays ("fully etched
    SWG-arrays"), and "only a one-step etching process is required" (p.3) implies but does not print a full-depth taper etch
    (alternative: `soi_strip` on all 11 rows; celo2014 audit limited `soi_strip` to the part the full-etch statement covers).
    chen2015c design rows: keep `soi` ("SOI channel waveguide", no etch statement in a simulation paper).
13. xiao2013 fab and process (Contract v7): keep `org_astar_ime` and `process_name` "IME CMOS fabrication process". The printed sentence
    is first person with the org and process named ("We fabricated ... through Institute of Micro Electronics (IME) CMOS fabrication
    process", p.5), and three authors list A*STAR IME as affiliation. Optional: the fuller printed form "Institute of Micro Electronics
    (IME) CMOS fabrication process, 248 nm DUV, 8-inch SOI" (p.4-5), in line with merged IME rows. The acknowledgment (NTU grants,
    A*STAR IME, SERC grant, p.6) is support / funding, not a facility statement.
