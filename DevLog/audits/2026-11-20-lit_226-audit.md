## Coordinator questions (recommendations)

1. cheung2010 fab (judgment 1 / (a)). Recommendation: keep `org_university_of_california_davis` borderline on the 3 rows. p.2 "Our
   integration process, similarly described in [3] and [4], utilizes the same method in fabricating AWGs, ..." is the D84a "our
   process" wording verbatim (chaw2025 / helgason2021 precedents, D637 / D678), and the process it names is the one of refs. 3-4,
   which carry this paper's UC Davis co-authors (Yoo, Soares, Fontaine, Baek). The eighth author sits at an Agilent measurement
   research laboratory and no sentence ties him to processing; D154's "authors spread over unrelated orgs" case (qi2024) had no
   process statement tying fabrication to one group. Revert = fab empty on the 3 cheung2010 rows (D80b strict reading).
2. Propagation losses with no shown measurement (judgment 2 / (b)). Recommendation: keep `author_estimate` (D76). There is no real
   precedent conflict: tran2019 p.4 prints "The waveguide loss is measured to be 1.2 dB/cm and 1.0 dB/cm at 1550 nm", a stated
   measurement with no method, so `measured` + method `unspecified` is right there; komljenovic2015 ("optimized silicon waveguides
   with a loss of 0.67 dB/cm", p.2) and cheung2010 ("the optical loss in the 2.5-um-wide waveguide section is ~2 dB/cm", p.2)
   state a property with no origin, which is D76's "performance value of unstated design / measured origin", as guzman2017
   (5 dB/cm). Proposed wording for the record: a loss the paper says was measured (method or not) is `measured`; a loss stated as a
   property with no origin is `author_estimate`.
3. komljenovic2015 ring pair (judgment 3 / (c)). Recommendation: keep one `resonator.ring` row. Q ~12 000 and FSR ~300 GHz are
   printed for "the rings", radii are not printed, and pair rows exist for exactly this case (fan2020_vernier_ring_pair,
   li2025b_si_vernier_rings, heim2026_ectl_vernier_rings, nejadriahi2024_vernier_rings); tran2019 split its rings because radii
   and per-ring values are printed. Two rows would copy one pair value onto each ring.
4. menezo1999 2.5 dB and "rejection" (judgments 5-6 / (d)). Recommendation: keep both as entered. The 2.5 dB is an estimated
   increment of the flattening modification relative to an unflattened PHASAR, not the device excess or insertion loss (none is
   printed); it stays in notes. "Rejection" stays `crosstalk_db`: the registry definition allows wdm crosstalk "when the type is
   not stated, with the stated wording in condition", and 15 merged out-of-band "rejection" rows use it (xia2007, khope2019,
   munk2019, ...); `slsr_db` on wdm is used for Bragg / CDC sidelobes. The Fig. 2(a) -7 dB marker reaches the nearest out-of-band
   shoulder (about 1538.2 nm), not the adjacent-channel position (+/- 1.6 nm), so the condition's "type not stated" is right.
5. cheung2010 ~51 ps condition (judgment / (e)). Recommendation: as patched (figure values 386 mA / 6.18 V, text values in the
   conflict note). Two figure sources (Fig. 3 data, Fig. 4(a) label) agree against one text sentence (sohn2021, D462). Revert = drop
   the m4 op (the conflict note was already present).
6. komljenovic2015 Fig. 4(d) and process (judgment / (f)). Recommendation: keep Fig. 4(d) out (D159). The caption groups (d) with
   panels (a)-(c) "of the laser without external cavity" and the 375 kHz minimum is close to the test-structure lasers (345-370 kHz),
