## Coordinator questions (recommendations)

1. zanzi2019 rows per generation and orgs (judgment (a)). Recommendation: keep. One row per part per generation is right: the two runs
   differ in fab, metal stack and loss budget (p.6 vs p.11), and the paper ties each value to one run. Stack geometry only on generation 1
   (the ams run says only "mostly unchanged", p.7; D402 does not reach a stack the paper does not restate). Fab org_upv on generation 1 per
   D533 (re-point when the NTC org exists); generation 2 org_ams_ag is the registry id for the printed "ams AG"; "Austria Microsystem" is
   printed once (p.7) and is an alias candidate only. process_name kept.
2. Loss-budget terms (judgment (b)). Recommendation: GC 9 dB halved to 4.5 dB `loopback_half` author_estimate: keep (feng2022 precedent:
   two-coupler budget term halved, loopback_half, author_estimate). MMI and taper terms: halve to `per_component` (patched; xing2015 D638
   is the same budget construction on a 2x2 MZI switch; revert = drop the value / scope ops on g1_mmi m1, g2_mmi m1, g1_gc_taper m1,
   g2_gc_taper m1). Bends stay out: the generation-2 values carry the citation directly ("come again from ... [28]", p.11) and the
   generation-1 value points to the authors' own bend paper ("see [38]", p.6; D259 risk), with no bend count printed. The 5.5 / 0.45 dB
   passive-waveguide terms stay `device_total` (no length).
3. 0.54 GHz as `bw3db_khz` 540000 (judgment (c)). Recommendation: keep. `switch_fabric` allows the parameter; merged non-thermal rows
   already use it (feng2011 p-i-n VOA 3 MHz, aflatouni2015 p-i-n phase shifter > 200 MHz, dong2021 piezo 120 MHz). `bw_3db_ghz` is an
   optical passband width and would be wrong. Registry follow-up: widen the definition text to "small-signal 3-dB modulation bandwidth of
   an electrically driven actuator (thermo-optic, MEMS, PCM, carrier injection / depletion, piezo)".
4. Eye ER at the lower drive, rise = fall rows, VpiL and capacitances (judgment (d)). Recommendation: keep all. "even lower drive voltages
   (+/-1.2 Vpp ...)" (p.11) is a typo: "even lower" and the Fig. 14 caption ((i)-(p) = 0.6 Vpp) agree, and the 0.6 Vpp panels show about
   1.0-1.3 ns edges, matching the printed about 1055 ps for Figs. 14(i)-(l). Generation 1 prints both edges explicitly (Fig. 6(a) trise =
   tfall = 60 ps); generation 2 prints one number for "rise/fall", entered on both parameters. VpiL stays in notes (no
   parameter; D438 candidate `vpi_l_v_cm`). Capacitances: `capacitance_ff` is allowed on phase_shifter, but the fitted values are per switch
   state and drive swing (p.14), not per arm; notes only.
5. kumar2022b split (judgment (e)). Recommendation: keep. CDC1 has its own measured (5.57 dB) and simulated (4.46 dB) values, heater and
   geometry; CDC2 has no standalone value, so its geometry on the cascade row with condition labels avoids a geometry-only row (rule 9).
   Fab org_applied_nanotools and no SDNI facility: correct (D83e).
6. albert1999 (judgment (f)). Recommendation: class `wdm.bragg_cdc` keep (subtype "Bragg / contra-directional coupler add-drop";
   amorim2017 MZI-Bragg OADM precedent). PDL keep with the port-not-stated condition and the added conflict note (D417). Port 2 "as low as
   10 dB" as worst-case `crosstalk_db` without `statistic: best`: keep; the lowest loss is the weakest suppression, and the statistic enum has
   no worst-case value (Fig. 2(c): the minimum sits near the Bragg wavelength, about 1528 nm). Fab: Photonic Integration Research Inc. is the
   vendor of the purchased PLC MZI the authors post-processed, not a wafer / film supplier, so rule 12 makes it a fab org; add it in the org
   round (fab, lit:albert1999 p.1 footnote 1) and then set `fab_org_ids` on this row. The authors' orgs stay out (passive grating-writing

7. Registry title of lit:zanzi2019. Recommendation: fix "023 Vcm" to the printed "0.23 V.cm" in `sources.csv` (and source.json) in the
