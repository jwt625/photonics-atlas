## Coordinator questions (recommendations)

1. pruessner2016 FOM as `insertion_loss_db` (judgment (a)). Recommendation: keep. Merged precedents enter
   actuation-induced loss on phase shifters exactly this way: aflatouni2015 current-induced excess attenuation at I_pi
   (`per_component`, excludes the zero-current loss), chen2023c 0.72 dB for a pi shift (0.024 dB/um x L_pi), feng2011
   added attenuation at 25 mA. The phase point in the condition and the dB/pi FOM in condition / notes keep the
   per-pi value recoverable; `loss_per_pi_db` stays a registry candidate.

   n_samples 5, with the patched note that the Fig. 4(d) curves spread widely around the line (L = 120 um about 3.8-3.9 dB
   by 2.3 pi), so it is not copied onto the L = 120 / 75 um rows (D254). No device-level figure reads were added: the
   paper prints no per-device loss.
3. pruessner2016 inferred wavelengths (judgment (c)). Recommendation: keep. The Fig. 3 caption states "broadband
   operation (lambda = 1490-1545 nm)", which is a stated operating span (rule 8). Caveat for the record: Fig. 3(b) of
   another device spans about 1475-1525 nm, and the Fig. 6(a) span 1470-1510 nm is shown for the L = 100 um device only
   (L = 40 um window not shown); both are within "inferred" tolerance.

   atlas/data/candidates.csv` already uses the id `li2025f` for a different paper (Materials 2025, 10.3390/ma18040837,

   2(g)) resonances sit within the 3.4 nm trimming range of the 1552 / 1572 nm resonances of Fig. 2(c), consistent with one
