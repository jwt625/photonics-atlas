## Coordinator questions (recommendations)

1. (a) matrix DC 0.1 dB "insertion loss" as `excess_loss_db` measured. **Keep.** p.13 models the matrix loss as the 1/(m x n) split
   plus coupler and crossing terms, so the 0.1 dB is the loss beyond the designed split (D43, parameter definition "loss beyond the
   ideal split"). The split ratios vary across the matrix (p.7, Fig. 2(a) caption), which a per-coupler excess term handles; an
   `insertion_loss_db` row would invite reading it as the through-port loss of a 50:50 coupler. Printed wording is in notes.
2. (b) Si3N4 waveguide 0.2 dB/cm `author_estimate`. **Keep** (D76 / D609: feldmann2019 Q and IL of unstated origin with an uncached
   supplement were ruled `author_estimate`). If the Supplementary Information is cached later and shows a cutback, switch to `measured`.
3. (c) Ring FSR 100 GHz `author_estimate` vs comb line spacing 100 GHz `measured`. **Keep both.** The FSR sentence gives no design /
   measured origin (D82a, D76); equating the soliton line spacing with the cold-cavity FSR is a physics inference the paper does not
   make. Precedent gao2025b sin_ring_r228-m3 ("ca. 100 GHz" author_estimate beside a 98 GHz soliton). Cross-note already on m2.
   Related basis check on the same ring: q_loaded > 5e6 `measured` is kept because the sentence states it of "the fabricated devices"
   (origin is the fabricated device, unlike feldmann2019 "an optical Q of around 10.000", D609); if the coordinator reads D76 strictly
   (no data shown), the alternative is `author_estimate` as bino2018 / heim2026. Same reasoning keeps the 4 dB/interface `measured`
   (D167).
4. (d) C band inferred on the five wavelength-conditioned rows. **Keep.** Rule 8 is satisfied: the matrix inputs are comb lines after
   a C-band EDFA (p.27), the Fig. 2(e) shaded input lines sit near 191-192.5 THz (C band), programming is at 1550 nm (p.8), and the
   comb pump is near 192.5 THz (Fig. 2(e)). Weakest case is the edge coupler (the packaged chip carries a comb spanning 180-205 THz);
   the note states the basis of the inference, so no change.
5. (e) Ring cross-section 0.82 x 1.50 um left out. **Keep out** (D159 analogue: which number is the height is not stated; filling it
   from the Damascene literature would use another source, rule 1). Kept verbatim in core_material and notes.
6. (f) Fab empty with `process_name` "Photonic Damascene process (ref. 56)". **Keep.** Contract v7 (named process, no named fab:
   keep process_name, fab empty, say so in notes); format as merged che2024 "photonic damascene process (ref. 17)". ji2022a /
   liu2024c carry org_epfl only because those papers state the fabrication place. The comb-chip authors are at EPFL, but D80b forbids
   filling fab from affiliation; the benchmark affiliation rule does not cover EPFL.
7. (g) bogaerts2020 0 rows. **Agree.** Fig. 3(d)-(f) (p.4) has no reference in its caption, but p.5 says it is "a two-cavity ring
   filter in a 7-cell hexagonal mesh", the device of Fig. 3(b), which the caption credits to ref. [44] (Perez et al., "Multipurpose
   silicon photonics signal processor core"; Perez and Capmany are co-authors here): reproduced own work (D259 / D408), and the review
   gives no platform, process, coupler values or measurement conditions. The Fig. 3(f) wavelength axis also carries a tick-label typo
   (1579.8, "1580.9", 1580.0, ...), another reason not to read values off it.
