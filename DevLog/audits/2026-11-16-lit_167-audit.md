## Coordinator questions

1. catalalahoz2026a foundry-specification rows (wg 1.1 dB/cm, MMI 0.15 dB, edge coupler 1.3 dB). Recommendation: keep as
   entered (no op). They are values the paper states for this chip's process at 1550 nm, and the waveguide / MMI rows carry
   them as their only performance metric exactly as the merged chen2024 pdk_waveguide / pdk_3db_splitter / pdk_pbs rows do (D432
   kept them with basis `specification`). No `exclude_values` entry is needed: `config/benchmark.yaml` admits only `measured`,
   `extracted_from_figure` and `derived`, so `specification` (and the `author_estimate` TBU / heater values) never reach the
   benchmark.
2. catalalahoz2026a TBU class. Recommendation: `switch_fabric.mzi_mesh` (patched): D158 sends a cell characterized as part of a
   mesh to `mzi_mesh` (ribeiro2016 mzi_cell); catalalahoz2026 put its in-mesh MZI extinction on the `mzi_mesh` row and kept
   `switch_fabric.other` only for the stand-alone nv_puc test cell. To keep `other`, drop the component op from the patch.
3. catalalahoz2026a Vernier identification. Recommendation: keep rows identified by Table 1 ring lengths (no op). The LC labels
   conflict in at least three ways: p.5 (LC1 -> x10, LC2 -> x6), p.6 / Fig. 4 caption (x3.6 = LC2 + LC3, x6 = hexagon + LC3,
   x10 = hexagon + LC1), Supp. Note 6 p.25 (LC2 -> 6, LC1 -> 10; LC2 vs LC3 "every 4 FSRs of LC3"); the Fig. 6 panel legends
   (Cavity 1 62.69 ps = 4.5 mm, Cavity 3 67.75 ps = 4.86 mm, hexagonal 75.24 ps = 5.4 mm, Cavity 2 83.61 ps = 6 mm) give yet
   another mapping. Only lengths, FSRs and T are mutually consistent.
4. zheng2024 fab. Recommendation: keep empty (no op). "Our device is fabricated using a home-developed technology" (p.19) is an
   own-process statement (D84a), but the authors' orgs are ECNU and SIOM (Y. Ma lists SIOM only, p.1), so the own org is not
   unambiguous (D154). Same group, same author split and same ruling as merged lit:wang2024c ("we fabricate ... PLACE", fab empty);
   nan2025 / zhou2025 got ECNU only because every author listed ECNU.
5. PLACE `process_name`. Recommendation: keep "PLACE" on zheng2024 (printed p.6 "using PLACE technology", p.19 "known as PLACE";
   Contract v7: named process with no named foundry, fab empty) and align the merged rows in a follow-up coord sweep. The merged
   PLACE rows are split: empty on lit:wu2023a (3 rows) and on lit:wang2024c, li2025, zhou2021a, zhao2025a, nan2025, zhou2025,
   li2024a, li2026a, zheng2026a and eo:hu2026a / eo:wu2022 component rows whose notes or tags name PLACE, while lit:zhao2026 holds
