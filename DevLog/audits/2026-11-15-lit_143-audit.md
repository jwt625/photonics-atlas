## Coordinator questions

1. martinez2016 reference p-i-n (D259 / D408). Recommendation: keep `cmp_lit_martinez2016_ge_pin_ref` (0.8 A/W `measured`, QE 66 %
   `derived`) and the APD gain / GBP rows as `derived`. The value sentences cite nothing and call it "the measured 0.8 A/W responsivity" of
   "a reference a p-i-n diode" (p.7) and "a measured Ge on Si p-i-n device" used for calibration (p.9); ref. 6 is cited for the design
   ("similar to our Ge p-i-n [6] with different implants", p.4) only, so D408's attribution test is not met. The value does equal the
   headline of ref. 6 (lit:derose2011, already in the atlas): cross-note added. Alternative (stricter reading of rule 3 / D159, identity of
   the reference device unstated): delete the ge_pin_ref component (2 metrics) and move the four M / GBP rows to `author_estimate` (they
   would rest on a cited unity-gain input).
2. chatterjee2019 0.76 fF / 416 ohm. Recommendation: keep both in notes (distiller's call). 0.76 fF is calculated for A = 100 um x 220 nm
   with a 3 um width that rests on the cited diffusion length (ref. 17), so it would be `author_estimate`, and its 100 um length matches
   neither fabricated row (105 / 115 um); 416 ohm is "obtained from the I-V of the photodiode" with no device named while Fig. 6 shows
   D1-D3 (D159). The garbled figure fonts block any figure read; no row uses them.
3. zhong2021 3.33 mW. Recommendation: keep `tuning_power_mw` with the definition in condition (chang2026a precedent, merged): the cavity
   "P_pi" is the power to detune by pi x FWHM, not a pi phase shift, so `p_pi_mw` would rank it against true pi-shift powers such as the
   same paper's 25.21 mW MZI value. The printed-input mismatch (3.46 vs 3.33 mW) is rounding of 0.11 nm / 0.10 nm/mW; note rewritten.
4. lin2022a `process_name` (applied). Recommendation: empty, as the five merged papers on the same AMF visible platform; the printed
   "visible spectrum PIC platform on 200-mm Si wafers" names no process or PDK (Contract v7). To keep the wording instead, drop the 11
   `process_name` ops.
5. martinez2016 breakdown condition (applied). Recommendation as patched: condition says the sweep is not stated, `wavelength_nm` empty.
