## Coordinator questions (recommendations)

1. zhang2025g scope, class and IL (distiller judgment (a)). Recommendation: keep in scope as `phase_shifter.other`, platform
   `other`. D411 excludes bulk crystal parts, not free-space chip-scale lithographic parts: merged free-space metasurface
   chips are in (lai2025 GaN metasurface as `micro_optics.metalens`, D532; yang2024 SOS metasurface PBS as `polarization.pbs`,
   both classed by function), and this 1 x 1 mm EBL-patterned LC cell is the same kind of part. D424 (LCoS switch fabrics) is
   only an analogy; it is not needed. Keep m5 `insertion_loss_db` < 2.22 dB as `simulated` (D83f: arithmetic on a simulated
   value; the only quantitative reflectance sentence is in the simulation section, p.5), now with the measured Fig. 8(c)
   dips (0.08-0.30 at 5-7 V) in notes. Alternative: delete m5 until `reflectivity_pct` is allowed on phase_shifter (registry
   gap 5); the % -> dB route is the rule-5 fallback only because no % parameter exists for the class.
2. Henry Royce Institute (zhang2025g p.12 Acknowledgment: "supported by the Henry Royce Institute for advanced materials
   through the Equipment Access Scheme enabling access to the RAITH - EBPG 5200 Electron-beam Lithography System at
   Cambridge"). Recommendation: org round as a borderline facility (name as printed "Henry Royce Institute", evidence
   `lit:zhang2025g p.12`), then facility on the single zhang2025g row. The sentence names the shared tool used for this
   device's EBL step (p.7) and where it sits, which is a "made use of" statement (rule 12), not only a grant (D80c / D83e
   cover program acknowledgements without a named facility use). Not a fab org. Alternative: treat the "Equipment Access
   Scheme" as a program acknowledgement (D80c) and leave facility empty.
3. zhou2022c and liu2021b simulation-only rows (distiller judgment (b)). Recommendation: keep both papers in scope as
   `free_space_emitter` design rows. D411 is about chip-scale vs bulk, not fabricated vs simulated; simulation-only papers are
   merged (arianfard2020 D611, li2025h D613, lin2021a). Both are chip-scale emitter optics (a 24.6 um metasurface over in-plane
   Ag nanoantennas; a 30 um Si metalens over an integrated antenna) in the he2026 class.
4. zhang2023f fab (distiller judgment (c)). Recommendation: keep fab empty on all eight rows. "We bond slightly different III-V
   material ..." (p.1) is first-person, but the "we" spans authors at two orgs (Nexus Photonics, UCSB) and there is no
   contribution statement; D154 (qi2024: authors spread over separate orgs stay empty) and D395 (fab = the org of the authors
   the sentence names) leave it empty, and "our platform" with passive "fabricated in a CMOS-like process flow" (p.2) is D84a.
   Choosing org_nexus_photonics alone would rest on affiliation (Contract v7: never from affiliation alone). If the coordinator
   reads "We bond" as a statement by all authors, D80b's two-org clause gives both org_nexus_photonics and the UCSB org, and
   only on the bonded laser rows (fp_laser, vernier, mopa, sil, soa, sld; not the SiN ring or waveguide, D515). A
   Nexus-authored-row mapping, if wanted for the benchmark, belongs in `config/benchmark.yaml` (D925 / D929 style).
5. zhang2023f 4.35 kHz (vernier m2, text) vs 4.15 kHz (mopa m1, Fig. 1(i) legend). Recommendation: keep both rows with the
   existing cross-notes. The text ties 4.35 kHz to the Vernier lasers in general ("such lasers"), the legend ties 4.15 kHz to the
   stand-alone MOPA, and the Fig. 1(i) noise floor reproduces 4.15 kHz; each value has one clear owner, so D159 (ambiguous sample
   identity) does not apply; the 5 % difference is a printed inconsistency or two devices (D417). Alternative: drop the text
   value as D159 if the coordinator reads both as one measurement.
6. zhang2023f ring Q about 1e7 and the photodetector. Recommendation: keep `q_intrinsic` `author_estimate` (D403: no spectrum,
