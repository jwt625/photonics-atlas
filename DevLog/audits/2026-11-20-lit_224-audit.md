## Coordinator questions (recommendations)

1. vandekerckhove2023 2500 %/W/cm2 basis (judgment 1). Recommendation: `measured` (patched). The situation matches D606 (luo2018: on-chip
   value from the paper's own quadratic fit, coupling correction not printed -> `measured`; zhao2026 m1, wang2018, zhao2025a). The cited
   precedents differ: lukin2019 describes its correction in an uncached SI, zhao2020 labels the axis "Estimated". Rule 4's "loss-budget
   term whose origin is not stated" needs a printed term; none is printed here. The journal paper's `measured` value is not the reason
   (rule 1), only consistent. Platform `lnoi_loaded_sin` (judgment 6): keep.
2. huang2016c 1.2 dB interfaces (judgment 2). Recommendation: keep as printed, `device_total`, `simulated` (no op). Halving to 0.6 dB
   per interface (D83f keeps it `simulated`) needs the interface count, which the text never states: Fig. 2(a) is a schematic and the
   text says the 3.5 mm bus is longer than the bonded isolator section without placing the die edges. Dropping the row loses the only
   transition value; it exists on the fabricated chip (D80e). Its `scope: device_total` tells readers it is not per transition; the
   garnet-junction precedents are per junction only because those papers print per-junction values.
3. huang2016c 2.3 dB (judgment 3). Recommendation: keep `author_estimate`, per_component (no op). The paper's arithmetic uses the
   simulated 1.2 dB (and 8.8 dB = 10 - 1.2 inherits it) and an "equivalent length of eight isolators" whose basis is not shown (3.5 mm /
   70 um would be 50). Mixed measured + simulated + assumed inputs: rule 4 / D452 (yang2026). Not `derived` (inputs not all measured),
   not `simulated` (D83f covers arithmetic on simulated values only).
4. huang2016c 10 dB with 1555 nm inferred (judgment 4). Recommendation: keep (condition patched). The value is the off-resonance gap to
   the Si reference trace in Fig. 8 (1555-1555.5 nm axis); `wavelength_inferred: true` with the reason is correct.
5. isolation_bw_nm 0.0097 from 1.2 GHz (judgment e). Recommendation: keep `derived` (D256: no nm form printed; kim2026, sohn2021,
   zhou2023a precedents). The level "isolation > 22 dB" is the paper's own reading of its 10-dB bandwidth, recorded in the condition.
6. Judgment 5 (> 20 dB span endpoints read off Fig. 9 inset, basis `measured`): keep; the printed value and 0.6 nm are measured, the
   endpoints are a figure read with uncertainty in notes.
