## Coordinator questions (recommendations)

1. olivares2021 waveguide losses on the ring row (judgment (a)). Recommendation: keep on `resonator.ring` (prop_loss_db_per_cm is
   allowed on resonator; Fig. 6(a) draws the whole ring as the SAHAS waveguide, so it is the ring's propagation loss in both states)
   with the cross-note already on the phase-shifter row. A separate `waveguide_platform.straight` design row would put a
   112.8 dB/cm plasma-loaded memory waveguide into the platform-loss views, which it is not. Registry: widen `prop_loss_db_per_cm`
   to `phase_shifter` (olivares2021 11.28 / 8.24 dB/mm p.6-7; kang2019 Fig. 2(b) zero-bias p-i-n loss, 3.05 dB/mm at Wi = 1 um, near
   0 above 2 um); if widened, move m4 / m5 to `cmp_lit_olivares2021_sahas_ps`.
2. olivares2021 platform empty and |k| = 0.15 as 15 % author_estimate (judgment (a)). Recommendation: keep both. D422: no wafer, BOX or
   substrate is stated or drawn. The coupling is a design choice ("a gap ... to achieve"), not stated as simulated (D82a); the
   fraction -> % rescale of a design value stays author_estimate as in the merged precedents listed above (not `derived`, which the
   registry uses for fitted or measured ratios).
3. kang2019 simulated additional loss at 2 pi as insertion_loss_db per_component (judgment (b)). Recommendation: keep on the 2.5 um
   row as the 2.9-3.2 dB range. It is stated for the whole 1-5 um sweep "almost regardless of Wi" (p.2), so the 2.5 um value lies
   inside it; D254 bars a single "typical" family value on one representative row, while a bounding range that the paper states for
   every width is a true statement about this design. The zero-bias loss is about 0 for Wi >= 2 um (Fig. 2(b)), so the injection part
   is the whole simulated loss; the `includes` text says so. Not copied to the siblings (fabricated MZI rows whose own losses are not
   reported).

   and 20 MHz "from a phase shifter device". No second candidate design exists, so D159 is not triggered. `phase_shifter.other`
