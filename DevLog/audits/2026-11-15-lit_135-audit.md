## Coordinator questions

1. akiyama2007 headline QD SOA (distiller Q1). Recommendation: keep out, as entered. The Sec. II device sentence and the Fig. 2
   caption cite [21], and Fig. 8 assigns the 2004 QD points to "Fujitsu[21]" (D259 / D408 figure clause, D455 / D465). Same for the
   QW comparison SOA (1.2 mm, 6-layer InGaAsP QW, Psat 17 dBm, p.3; Fig. 7 "Pout = 17.1 dBm" at 0.9 A): it shares Figs. 6 and 7 with
   the [21] data and the paper does not say who made or measured it, so its provenance is ambiguous (D159 analogue); the report folds it
   into the [21] list without a separate reason. Weak point on record: Fig. 17 is kept only because nothing cites it; ref. [52]
   ("unpublished") exists but is never cited in the text.
2. dostart2020a 13.1 dB (distiller Q2). Recommendation: keep out of `isolation_db` (sohn2018 / kittlaus2020a, D419 / D513): the paper
   defines isolation as |S32|^2 / |S23|^2 "assuming perfect filtering" (p.3) and builds only the non-reciprocal section. Keep the
   `nonreciprocal.other` row: unlike kittlaus2020a (D419, mode converter) the device is built and named as the isolator core, and its
   18.1 dB conversion insertion loss is measured. Note: D419 decided a `conversion_contrast_db` registry extension, but
   `component_parameters.yaml` still has no such parameter; when it lands, enter 13.1 dB (p.4, Fig. 3(c)) on this row.
3. kaspar2015 internal values (distiller Q3). Recommendation: keep m3, m4, m8, m10 as `author_estimate`. Rule 4 names "a cited input"
   as the author_estimate case, and D429 (ahmadi2022 net gain on a cited loss) is a direct precedent; rule 3's "values computed from
   them" reads as values computed from cited values only. Weak point on record: p.1 says the paper "first give[s] the static performance
   of a hybrid III-V/silicon SOA that we have previously presented in [14]"; grammatically "that we have previously presented" attaches
   to the SOA, and no value sentence or figure cites [14] except the loss estimate, so D408 keeps the measured rows. If the coordinator
   reads the p.1 sentence as attributing the static values to [14], all 11 rows go (delete_components
   cmp_lit_kaspar2015_hybrid_soa_packaged).
4. yang2024c Q 1.3 M (distiller judgment; text "intrinsic", figure Q_L). Recommendation: keep `q_loaded`, `measured`, conflict in notes
   (D417). The Fig. 1(e) label names the fitted quantity; the dips reach about 0.85 transmission (cached render). Audit arithmetic, not
   a data value: if the disk is under-coupled, Q_i = 2 Q_L / (1 + sqrt(0.85)) is about 1.35 M, within about 4 % of Q_L, which matches
   the paper's wording; if over-coupled, Q_i = 2 Q_L / (1 - sqrt(0.85)) would be about 33 M. The paper does not determine the regime from the data, so no
   `q_intrinsic` row (D403). 0.5 dB/cm stays `author_estimate` (D76: group index not stated).
