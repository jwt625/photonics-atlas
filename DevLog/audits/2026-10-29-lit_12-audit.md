## Rulings on the batch report's judgment calls

1. **minami2023 signal-to-idler CE as power_conversion_efficiency_pct (977-1259 %): kept.** The parameter is defined
   "as defined by the paper", the dB-to-% conversion is exact arithmetic (D82d, derived), and merged precedent
   ding2022 already stores FWM signal-to-idler CE (idler out / signal in) in this parameter from printed dB values.
   For a parametric converter with gain the same ratio exceeds 100 %; that is physically meaningful (net conversion
   gain), not a unit error. Deleting the rows would leave the component without a performance metric (D49 deletion).
   The patch adds the missing reference plane (module ports, p.3 Sec. III-B) and states in condition that values above
   100 % are net conversion gain. Optional registry follow-up (no skipped value, so not a D81 gap): a dedicated
   `conversion_gain_db` for signal-to-idler CE would separate it from pump-to-product efficiencies; it would repoint
   ding2022 and minami2023 together.
2. **liu2025 org_imec on the hybrid SOA / taper / GC / DFB / tunable laser: endorsed.** p.3 Sec. 2B-2C: the SiPh
   circuits "were realized on imec's 300 mm SiPh platform" and the laser target chip "was fabricated at imec"; the Si
   waveguide, grating and Vernier rings are part of each component. Same treatment as merged keyvaninia2013 (Si
   circuit fab org on a hybrid laser). The QD coupon pre-fabrication / printing ("we", authors at Ghent University -
   imec, Innolume, EV Group, IMEC) is not unambiguous (rule 12) and stays a note.
3. **tian2021 fab org_epfl + org_purdue_university: endorsed** (p.11 author contribution: fabricators at EPFL and
   Purdue; "Samples were fabricated in the EPFL CMi, and Birck Nanotechnology Center"; D80b two-org rule; the
   assisting author is EPFL anyway, D395). Facility org_center_of_micronanotechnology endorsed. Plasma-Therm
   ("sputtered ... through foundry services", p.10; "AlN deposition was performed at", p.11) is a film-deposition
   supplier: a note under rule 12, not a fab org and not a shared facility; no registry row needed.
   **ledezma2022 org_caltech: endorsed** (p.3 "To fabricate the device, we use ..."; all authors Caltech, the first
   author also at JPL, which the paper prints as part of Caltech; D80b satisfied).
4. **ma2021 four-port device as nonreciprocal.circulator: endorsed.** p.3 / p.6 / p.7: a genuine circulator
   (1 -> 2 -> 3 -> 4 -> 1, Tables 1-2) that also works as an isolator between opposite-side ports; the song2025a
   routers moved to nonreciprocal.other (D252) because they are not circulators.
5. **ledezma2022 OPG gain basis: derived** (not measured, not author_estimate). The gain is computed from fitted
   model parameters under stated approximations (D80a "model-parameter extraction with stated assumptions"); no
   assumed numeric input enters Gs = E_OPG / a, so author_estimate does not apply. Patched (m3, m4; m2 also derived
   as authors' arithmetic).
6. **ghosh2012 isolation values from Fig. 5 annotations, wavelength = panel span (inferred): endorsed** (p.3 Fig. 5
   render: annotations 11 / 10 / 6.8 / 2 dB; spans 1511-1513, 1501.5-1504.5, 1503-1509, 1520-1540 nm).
