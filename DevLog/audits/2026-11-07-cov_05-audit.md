## Rulings on the distiller's questions

1. kashiwazaki2021 zero rows: keep dropped. The overview re-presents three earlier own papers: Fig. 1(d) SHG cites [9]
   (p.3 caption), the module paragraph opens with [17] and continues into the 0.5 / 0.7 dB coupling and 2.0 / 2.3 dB
   module losses (p.2-3), the PSA section and Fig. 3 cite [18] (p.3-5), the squeezing Fig. 4 cites [8] (p.6; apparently
   meant [9]). D259 / D259a / D408 apply to all of them; the waveguide also differs from kashiwazaki2021a (about 5.0 um
   layer, 1200 %/W at 1550 nm vs 8.0 um, 820 %/W at 1545.3 nm), so no value transfers.
2. stokowski2024 laser.comb row: keep (D396; comb-only parameters live on laser; D83b for 5.8 GHz line spacing).
   Cross-notes are present on both rows.
3. hazan2022 T0: threshold-only stands. The paper fits T0 to the transparency current density and says explicitly it
   does not use Jth (p.3 Sec. IV; p.4 Fig. 4(b)); registry definition is T0 of the threshold current. Note on the
   laser row is correct.
4. Registry gap, frequency_converter bandwidth / crosstalk: gap confirmed. If added, li2025d 110 nm 3-dB bandwidth is an
   estimate by reciprocity (p.5; author_estimate); the 25 dB figure is a suppression relative to the single-stage
   reference (p.6, Fig. 4(d)), so the device value would be the 40 dB signal-to-crosstalk ratio (p.6, Fig. 4(c)).
   Join the D429 frequency_converter bandwidth candidates.
5. Registry gap, frequency_converter wavelength accuracy / tuning: tuning range gap confirmed (xin2024 up to 12.1 nm
   red shift, p.9 Fig. 4 caption; > 100 nm cladding trim, p.4). The 73% within (737 +/- 5) nm (Wafer A, 84 of 280
   devices, p.4) and ~96% (Wafer B, p.4) are yields, not a +/- spread, so wavelength_spread_nm would not hold them; a
   yield parameter would be a separate proposal.
6. Registry gap, amplifier pump suppression and gain per W per mm: gain_db_per_w_mm confirmed (chen2025a 0.78 dB/(W mm),
   p.6; chang2026 notes carry the same kind of value). Pump suppression: not needed for dean2025, the coupler's
   extinction_db rows already carry it (13 dB per coupler at 1575 nm; the 26 dB is two in series).
7. Conversion efficiency in dB: no new parameter. Rule 5 keeps linear values in % parameters; the dB -> % conversion
   is derived with the printed dB in notes (abe2025 precedent stores conversion gain in %).
