   figure-read worst case. No op.
2. kim2014 fab AIST. Recommendation: keep, and drop "borderline". The paper has two first-person fabrication statements (p.5 "we used a
   simple reactive ion etching"; p.7 "We fabricated such a diversity circuit") and all authors are at one institution, which is what
   D80b / rule 12 require; the p.8 staff thanks (D84b) are supporting only. Patched as note rewrites on the 5 rows (to empty the fab
   instead, set `fab_org_ids` empty on the same 5 rows).
3. wu2020b MUX / DEMUX excess loss scope. Recommendation: `device_total` of the back-to-back reference pair (patched). The Fig. 5 panels
   are titled "Mode MUX + Mode DEMUX" and show one spectrum per link; the text deducts these values once from the MUX + 10 crossings +
   DEMUX chain, which only works if they are pair totals; no halving is stated, so a per-device value is not available. Alternative: keep
   `unspecified` (drop the m1 / m2 ops and the component note op).
4. li2013 > 17 dB back-reflection basis. Recommendation: keep `derived`. The authors compute it from their own measured 0.2 dB ripple
   under a stated (pessimistic) assumption, which is D80a model extraction with stated assumptions; merged precedents for ripple /
   fringe-contrast reflections are `derived` (cmp_lit_shen2019_gesbs_gc-m7, cmp_lit_liu2022_sin_inverse_taper_edge_coupler-m3 / m4,
   cmp_lit_korcek2023_apodized_np7-m4). `author_estimate` would apply only if
   the input were assumed or cited. Only the wavelength flag was patched.
5. li2013 fill factor. Recommendation: keep 0.469 `derived` (D253). The p.3 definition (trench / period) and Table II (trench 0.18 ->
   0.34 um at period 0.64 um, 0.34 / 0.64 = 0.531) both confirm fend is the etched fraction. No op.
6. chen2022d modulator values (Vpi 0.67 / 0.70 V, VpiL ~2.2 V cm, EO bandwidth about 45 GHz, on-chip IL 5.8 +/- 0.2 dB, ER > 25 dB,
   14 dB chip total, 4.49 fJ/bit). Recommendation: stay out (rule 2); list chen2022d (OE 30(14) 25308, DOI 10.1364/OE.458431) as an
   EO-atlas candidate in DevLog-007 (D168 / D425 / D451 precedent). It is not in ../eo-modulator-atlas (checked `data/devices.csv` and the
