## Questions raised by the distiller (evidence-based recommendations)

1. mizukami2011 scope (D411). Rule applied: D411 as written ("integrated / chip-scale photonic components and
   fiber-coupled passive parts; a discrete bulk (mm-scale polished crystalline) resonator is out", D233 analogue) read
   together with the registry classes (`switch_fabric.mems`, `switch_fabric.wss`) and the merged rows. Evidence: the
   switching fabric is free-space optics between fiber collimator arrays and two two-axis MEMS tilt-mirror arrays (p.2
   Sec. 2, Fig. 1), actively controlled by peak-search / stabilization software (p.2-4), packaged as a 436 x 350 x 355 mm
   19-in rack module (p.2). Literally it is neither chip-scale (the optical path is free space across the fabric) nor
   passive, so D411's first clause does not cover it; it is also not the bulk-crystal case D411 excludes. Merged
   precedent of the same kind: ryf2002 (1296-port free-space 3D MEMS OXC, switch_fabric.mems, other), iwama2015 (1x93
   LCOS WSS, other), yang2020 (two LCoS WSS rows, other) - four rows, all merged before D411 and never re-ruled.
   Recommendation: keep (no patch here) and record a D411 clarification: fiber-I/O free-space switch fabrics built on
   lithographic MEMS mirror-array or LCoS chips are in scope as switch_fabric (platform other), the class subtypes exist
   for them. If the coordinator instead rules them out, delete cmp_lit_mizukami2011_mems_oxc_128x128 (10 rows) and, as a
   cross-batch follow-up, ryf2002, iwama2015 and both yang2020 rows (not only ryf2002).
2. pathak2012 AWG insertion loss -2.6 dB and crosstalk 21.5 dB: keep out (endorsed). The only body sentences giving the
   values carry the citation [18] (p.7: "-2.6dB [18]", "21.5dB [18]"); [18] is the authors' ECOC 2012 paper with the same
   title (p.2 reference list). D408 keeps journal-extension values "unless the value sentence attributes the value to the
   earlier paper"; here it does. The abstract (p.1) and the conclusion (p.8) repeat both without a citation, but they
   summarize the body. Fiber-to-fiber < 15 dB as author_estimate: keep (endorsed). The paper calls it estimated and never
   shows its inputs; 2.6 + 12 = 14.6 dB is consistent with "better than 15 dB" but the paper does not state that sum, so
   rule 3 ("computed from cited values") is not established; the note records the possible dependence.
3. goh2001:
   a. 42 % coupling ratio author_estimate: endorsed. p.5 Sec. IV-A gives it only as the input of the loss-budget penalty
      ((4k(1-k))^2 -> 0.2 dB) with no measurement method or structure; skill rule 4 ("loss-budget term whose origin the
      paper does not state"); D418 did not extend D167 to such values.
   b. 0.2 dB/stage author_estimate: endorsed. It is the residual of a budget that uses the assumed 0.4 dB/point fiber
      coupling (p.5); 6.6 - 0.8 - 2.18 - 0.2 = 3.4 dB over 16 stages = 0.21 dB, consistent.
   c. About 500 mW per MZI as p_pi_mw: endorsed. Registry: "electrical power for a pi phase shift". Each MZI has a
      half-wavelength path difference, bar at zero power and cross when heated (p.2 Sec. II-B), so ON = a pi shift; after
      trimming the OFF bias is < 3 mW (p.5, Fig. 8), so the ON power is the switching power, not bias + switching. The
      value is the ON power at minimum insertion loss of the Fig. 9 example path (render: 2nd MZI 500 mW, 1st MZI about
      530 mW at the ON marker), basis measured, qualifier approx; consistent with the 1.04 W unit average for two MZIs
      (p.7). Not a per-2pi value.
   d. Wavelength of the loss-budget rows (distiller Q5): the paragraph states none; Sec. IV-A names 1.55 um light for the
      matrix measurements. Kept 1550 with wavelength_inferred on the waveguide rows and made the 0.2 dB/stage and the
      intersection crosstalk consistent (patched).
4. Classes and orgs:
   a. popovic2006 three filters as wdm.mrr: endorsed (D400). The stages are channel add-drop filters designed for 40 GHz
      channels on a 100 GHz WDM grid with a through / drop / add path (p.1-2, Fig. 1(a)); not laser-cavity or test rings.
      The 12 dB/cm ring loss on a separate waveguide_platform.bend row is right (prop_loss not allowed for wdm; the paper
      names no separate test ring, so resonator.ring would invent a device). Design rows as simulated: endorsed (synthesis
      and 3D FDTD, p.2); the 100 GHz grid moved to author_estimate (patched).
   b. yang2010: 4x4 non-blocking switch switch_fabric.mzi_mesh and 2x2 element switch_fabric.other: endorsed (D158: the
      4x4 is an NxN fabric of six MZI elements and six crossings, p.3 Fig. 1; the element is characterized as a typical
      stand-alone 2x2 switch, p.3 Sec. 2.2, Fig. 2(b)-(c)). Per D422 / lu2016a its on-state FCA loss and Von move to notes
      (patched); 15 dB crosstalk, 50 nm bandwidth and the on-state > 15 dB stay.
   c. piggott2015: wdm.other endorsed (registry subtype text "incl. inverse-designed"; 1300 / 1550 nm band splitter, p.1-3).
      Fab org_stanford_university endorsed: author contributions "A.Y.P. designed, simulated, fabricated and measured the
      devices" (p.4) and all authors list Ginzton Laboratory, Stanford University (p.1); D395 (fab = org of the authors the
      fabrication sentence names). No facility acknowledged (the Methods name the tools, not a facility; p.5).
5. yang2010 IL 0.6-5.8 dB scope unspecified (distiller Q6): endorsed; spectra are normalized to the sum of the four output
   ports (p.5) and the IL reference is not stated (p.6).
6. mizukami2011 switching time as rise_time_us (distiller Q7): endorsed for consistency with ryf2002 and D422 (switching
