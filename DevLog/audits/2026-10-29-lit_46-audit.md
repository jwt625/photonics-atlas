## Rulings on the distiller's questions

1. **jin2021 intrinsic Q (D403).** Not endorsed. The coupling regime is not determined from the data: the doublet
   fit of an amplitude transmission spectrum has the same under / over-coupling ambiguity as a singlet fit, and the
   paper resolves it by design (under-coupled pulley coupler, p.11; racetracks designed critically coupled, p.12).
   The ring-down (124 ns) fixes only Q_L. D403 applies: q_intrinsic `author_estimate` (14 rows) and the intrinsic
   finesse with it; q_loaded stays `measured`. The values are physically consistent with the under-coupled branch
   (the Q_i dip near 1510 nm attributed to N-H absorption, p.3), which supports the regime but does not measure it.
2. **jin2021 structure.** Endorsed. Kerr-comb states of a self-injection-locked laser are operating states of one
   laser (laser.sil and laser.comb are subtypes of one class; D396 one row per class, rule 9 within the class); the
   comb rates go to repetition_rate_ghz (D82g / D83b: the paper says repetition rate and characterizes dark pulses).
   The 0.1 dB/m platform row: endorsed as a waveguide_platform.straight row with `author_estimate` (inference inputs
   and resonator not stated, p.7; D159 analogue keeps it off the ring rows); the 0.045 dB/m value is cited (ref. 31,
   not entered). The 30 GHz SIL configuration has no row: correct, its only value (1 Hz2/Hz white-noise floor,
   p.3 Fig. 2(b) caption, which prints 20 GHz for this resonator) has no parameter; a gap-fill can add the row if
   the frequency-noise parameter is accepted (D254 sibling-row precedent).
3. **Value conflicts.** (a) nader2025 DFB tuning rates: main text p.5 26.5 / 16.6 / 24.0 pm/mA, supplement text p.15
   26.6 / 16.6 / 24.6; the Fig. S4(b) bars read about 26.4 / 16.6 / 24.0 (p.16 render). D159 is not triggered (one
   laser per wavelength, sample identity unambiguous). Recommendation for the gap-fill: enter the main-text values
   (supported by the figure) with the supplement values in notes. (b) zhang2026a divergence: intro p.2 12.3 x 31.5
   deg vs p.11 text and Fig. 14 label 11.6 x 32.6 deg at 300 mA: same device, not a D159 case; the Sec. 3 value has
   two concordant locators (text and figure label) and is correctly entered; intro value in notes. p.3 simulated
   9.5 x 21.8 deg vs p.4 / Fig. 2(d) 11.0 x 32.9 deg: the figure-backed value is entered, endorsed.
4. **Basis / scope.** (a) nader2025 edge-coupler losses `author_estimate`: endorsed. Both values are parenthetical
   setup facts with no method (3 dB +/- 1 dB "coupling efficiency" to the lensed fiber, p.5; 6 dB lensed-fiber
   coupling into the OPO chip, p.7, per facet or total not stated): skill rule 4 "loss-budget term whose origin the
   paper does not state". D167 (shi2024) had a stated calibration with a lensed-fiber pair; it does not extend to an
   unexplained setup number. (b) lim2026 0.58 % `author_estimate`: endorsed. The measured quantity is detector power
   over power incident on the trap; the stated efficiency is that ratio converted with the measured source divergence
   and an assumed isotropic emitter (p.4), i.e. it rests on an assumed input. (c) yang2024 polarization.pbs in scope
   under D411: endorsed. The device is a lithographically patterned (EBL, ICP-RIE) 500 nm Si metasurface on an SOS
   wafer, 1 mm2 arrays, which the paper calls a chip-scale PBS (p.2), intended for vapor-cell windows; it is not a
   bulk polished crystalline part. Precedents: oh2023 free-space metasurface fiber couplers and wang2023c facet
   metasurface are merged. Class pbs over micro_optics.metalens: endorsed (function is polarization splitting; per_db
   allowed).
5. **Fab / facility orgs.** nader2025 NIST on the bonded-wafer rows: endorsed (p.2-4 "We develop a fabrication
   process", "We fabricate and characterize DFB lasers"; every author has a NIST division affiliation, CU Boulder
   only as a second affiliation, D154 / D83c); empty on the 1064 nm ring and the separate OPO chip (fabrication site
   not stated): endorsed. lim2026 org_university_washington: endorsed ("We design, fabricate, and test", p.1; all
   authors UW). jin2021 empty (unnamed CMOS foundry, p.1; Anello only co-designed and is acknowledged): endorsed.
   zhang2026a, zhang2025b, yang2024 fab empty (passive voice): endorsed. Missing orgs confirmed absent from
   `organizations.csv` / `org_aliases.csv` (see below); facility_org_ids should be set once registered.
6. **Registry gaps.** See below; values confirmed at their locators except the nader2025 tuning range (family
   statement).

Further judgment calls of the report: nader2025 60 GHz mode spacing on all three DFB rows (family statement p.9, same
