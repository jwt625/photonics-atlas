## Points checked as asked

- kittlaus2018 class (D419): `mode_converter.converter` correct. The measured quantity is the frequency-shifted, mode-converted output
  P(M3p1) / P(M4p2) for forward vs backward injection (p.6, Fig. 3(c), (d)); no transmission isolation of an unshifted signal is measured,
  and the paper itself calls isolators a future step (p.1, p.7). Same construction as kittlaus2020a (D419) and sohn2018; cheng2025 (merged,
  `nonreciprocal.isolator`) differs because it measures isolation. The 38 dB, > 19 dB over the FWHM, 20-40 dB range and 37 dB stay in
  notes until `conversion_contrast_db` / `sideband_suppression_db` exist (D419 registry candidates, not yet in component_parameters.yaml).
- kittlaus2018 "< 1 dB insertion loss" (D159): see finding and Q2. 0.4 dB/cm x 2.39 cm = 0.96 dB reproduces the bound; the 0.2 / 0.4 dB/cm
  match Supp. Table I alpha 4.6 / 9.2 m^-1 (4.343 x alpha / 100 = 0.20 / 0.40 dB/cm), which p.32 says come from experimental measurements,
  so `measured` on m1 / m2 with the printed "estimated" in notes is kept (rule 4). `derived` for the bound kept.
- qu2024 net PG `derived`, ref_plane on_chip (D166): kept. p.30 Eq. (3) divides the output signal peak power by the CW signal power at the
  waveguide input, and p.9 says quoted powers exclude the ~4.2 dB / facet coupling loss, so the printed net gain is the fiber-side reading
  corrected by the own measured coupling loss (ye2021, kuyken2011 precedents). On/off gains (Eq. (4), same output plane) `measured` with
  ref_plane empty (foster2006 precedent) kept. Both rest on Eq. (2) with the pulse width T (presumably the ~180 fs pump width; whether the
  signal pulse width was measured is not stated): treated as the standard extraction, not flagged.
- qu2024 signal wavelength 1535 nm: arithmetic correct (1557 - 22) and consistent with the Fig. 4(a) signal line; set as inferred (Q4).
