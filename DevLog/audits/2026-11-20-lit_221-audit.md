## Coordinator questions (recommendations)

1. ding2012 (judgment (a)).
   a. One row per fabricated w1 sample vs one family row. Recommendation: keep per-sample rows. Each sample is a different drawn
      w1 with its own measured marker in Fig. 6(b) (rule 9, D32; cheng2023 / pita2023 precedent); D165 covers values regressed over
      a family, which this is not. The family bound stays in notes (D254).
   b. L = 100 / 120 um rows. Recommendation: delete (patched; revert = drop the two delete_components ops and the w324_l140
      notes op). The vector data give -0.19 / -0.35 dB at 1540 nm (not 0.5 dB), with 1.0 / 2.1 dB ripple within +/-5 nm and
      excursions above 0 dB; on the L = 140 um device the same trace method gives +0.02 dB where the paper's Fig. 6(b) metric
      gives -0.49 dB, so a trace point is not the paper's metric and would rank the L = 100 um device above its own headline.
      The paper states only "similar" T_c for L 100-140 um (p.6). If kept, the values must be 0.19 / 0.35 dB with these notes.
   c. w1 318 / 323 / 329 nm from the Fig. 6(b) axis. Recommendation: keep `extracted_from_figure`. They are data x positions of
      plotted samples (not scale-bar measurements); the vector marker centres sit at 317.96 / 322.99 / 328.94 nm and 329 nm is the
      printed end of the fabricated range (p.6).
   d. Conversion loss scope unspecified. Recommendation: keep `unspecified` / method `unspecified` (setup and calibration only
      cited, ref. [12]; same group's liu2011 merged rows use the same form). Basis `extracted_from_figure`.
2. ma2019 (judgment (b)). Recommendation: keep Table 1 "extinction ratio" as `per_db` with the notes. The paper does not define
   it, but its numbers fit the output-port ratio and not leakage relative to input: air-clad TE00 input has measured cross-port
   crosstalk < -20 dB (p.5) and Table 1 ER > 19 dB, i.e. about 1 dB lower, as expected for wanted / unwanted with about 1 dB IL;
   Figs. 5 / 9 support > 15 dB (TM00) and > 14 dB (SiO2 TE00, cross-port trace up to about -14 dB). Fab: keep
   org_applied_nanotools (air-clad, p.4 names the company with the process) and org_astar_ime (SiO2-clad, p.6 names the place
   and the 193 nm process), each only on its own row (D515, D463).
3. tan2016 bw_3db_nm (judgment (c)). Recommendation: keep a bound, raised to `ge` 120 nm (patched; revert = drop the m5 op). The
   100 nm rested on the O-band definition, which the paper does not print; Fig. 5 spans 1250-1370 nm and both CE traces stay within
   about 2 dB of 0 dB over it, so the plotted span gives the bound (pita2023 / lin2022 span-bound precedent, simulated per D454).
   Notes-only is the alternative if the coordinator prefers no figure-derived bound on a design row.
4. nelan2022b (judgment (d)). Recommendations, no ops: keep crossing < 0.01 dB as printed with the Fig. 3(a) note (D417; confirmed
   -0.039 to -0.043 dB); keep S_MMI 8 um as `pitch_um` (Fig. 2(d) marks it between the output centre lines; 19 merged splitter rows
   use pitch_um for port centre spacing); keep one MMI row for splitter and combiner (one design used both ways, p.4-5; rule 9);
   keep the facet 8.75 dB `author_estimate` per_facet (equal-facet split, D462 / D514); modulator values out under rule 2;
   fab empty with the NanoLN note (D80b, D428 / D431).
5. nelan2022b as an EO-atlas candidate (DOI 10.1364/oe.453050): the EO atlas holds only the group's later nelan2022 /
   nelan2022a; recommendation: add to the EO-atlas candidate queue (DC Vpi 4.0 V at 10 mm, ER 23 dB, 37.5 GHz with UV15, total IL
   21.0 dB, p.1 / p.9-12), no action in this repo.
