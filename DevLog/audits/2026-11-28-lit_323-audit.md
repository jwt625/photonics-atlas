## Coordinator questions (recommendations)

1. papes2016 platform `silica` vs `soi` (judgment b). **Keep `silica`.** D82f is binding (platform = layer at the
   fiber-facing facet). At the facet the fiber couples into the SiO2 rib (w x d) whose index is raised by thin Si3N4 sheets;
   the 150 x 220 nm Si tip is fully delocalized there and the mode is "pulled into the upper cladding" (p.5, Fig. 3). Precedents
   with a buried Si / SiN taper under a SiO2 facet waveguide: su2026 (D441), fang2016 (D752 patched soi -> silica), jia2017,
   nauriyal2019. The full stack is in `core_material`. `sin` would be wrong (20-30 nm layers, SWG-graded).
2. papes2016 scope of the overall values (patched). **Accept `per_facet`** (D707 edge-coupler convention). The facet overlap
   stays `per_facet` with `excludes` (cheben2015) and eta2 stays `on_chip_excess` (cheben2015 swg_n1-m6). Drop the four ops to
   keep `per_coupler` if preferred; effect: the 0.42 / 0.75 dB design values are then invisible to the edge_taper per_facet
   ranking (design rows are not heroes anyway).
3. dai2011a ER band (judgment c, patched). **Accept 1455-1650 nm, > 10 dB, no inferred flag.** The printed value is a width
   ("about 200 nm"); the 200 nm equals the plotted span 1.45-1.65 um, but at 1.45 um the TM0 ratio is 9.4 dB, so the row's lower
   edge moves to the 10 dB crossing (about 1.454 um on the curve paths). The upper edge is the plot limit (ratio still 13 dB
   there), noted. Alternative: keep 1450-1650 as the printed "about" span with the reading note. A `per_bw_nm` parameter
   (registry gap 3) would hold the printed 200 nm directly; defer unless more rows need it.
4. dai2011a IL from simulated curves (judgment c). **Keep both rows `simulated` (D454)** with the vector readings: TM0 cross
   0.07 dB, TE0 through 0.14 dB (patched from 0.15). Readings from the PDF vector data agree within 0.01 dB between curve and
   marker.
5. dai2011a gap / coupling length / radii only in notes (judgment c). **Keep in notes**; if the coordinator widens the
   registry (gap 1 / 2 below), the rows are gap_nm 203 (Fig. 5 caption, `design_target`), coupling_length_um 4.5 (p.5),
   radius_um 20.0 / 19.3 / 18 (p.5, arm in condition); R0 stays out (4 vs 3 um conflict).
6. michaels2018 Fig. 8 and the 8 nm reflection band (judgment a). **Keep both out of metric rows**; bounds now in component
   notes (patched, D159). Fig. 8 points are separately optimized designs with only the 65 nm point labelled (D156); the 8 nm
   -20 dB width has no parameter (registry gap 4).
