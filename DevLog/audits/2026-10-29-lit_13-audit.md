## Rulings on the batch report's judgment calls

1. abe2025 vs umeki2010 class: one class, frequency_converter.sfg_dfg, for both (patched). Both are NTT PPLN chi(2)
   DFG / OPA wavelength converters whose useful output is the converted light (abe2025 p.2 Sec. II-A, title; umeki2010
   p.5-7). Registry: sfg_dfg = sum / difference frequency generation; amplifier.parametric is used in the merged table for
   devices characterized by signal gain (riemensberger2022, kuznetsov2025), while the FWM wavelength converter ding2022 is
   frequency_converter with its idler / signal conversion efficiency (printed in dB) stored in power_conversion_efficiency_pct
   (derived). umeki2010's module metrics (%/W) cannot live in amplifier. Consequences: abe2025 conversion gains -> % (1000 /
   > 1995, derived); abe2025 NF rows deleted (no frequency_converter NF parameter, values in notes); umeki2010 +8 / +4 dB
   conversion efficiencies become rows (misses). No new parameter invented; conversion_gain_db stays a gap (below).
2. wang2026b QE 57 % in power_conversion_efficiency_pct: not endorsed. p.10 defines QE as a photon-flux ratio; the registry
   parameter is a power ratio (the same point is about 139 % as a power ratio). m8 and the Q-derived ~70 % (m9, same
   definition) are deleted; values kept in the component notes; gap below.
3. qiu2025 HZDR as facility: endorsed. p.2 "Erbium ion implantation was performed at HZDR" and the acknowledgment
   "samples ... fabricated in the EPFL CMi and HZDR" name places, not a fabricating org (rule 12 "performed at"); no author
   is at HZDR; fab_org_ids empty (D80b passive); CMi facility consistent with merged EPFL rows.
4. vandekerckhove2025 0.18 nm/K: not endorsed; deleted under D159. The text (p.5) attributes it to "our platform" and does
   not name the device; the Fig. 5(d) wavelength (about 1560-1570 nm) makes a foundry-platform device plausible but that is
   an inference from the plot (D156). Noted on both components.
5. umeki2010 2400 %/W excluded under D259a: endorsed. p.3 "Fig. 4 shows a typical SHG tuning curve ... [20]" and the
   2400 %/W sentence that follows read Fig. 4, whose caption cites [20]; the 0.2 nm FWHM (p.4, Fig. 4) and 148 mW / 92 %
   (p.5, Fig. 8 [20]) likewise. The pigtailed-module 2200 %/W (p.5, Fig. 9) is a new measurement: kept.
6. cai2021 / starnault2024 saturation power with the source definitions: endorsed. psat_in_dbm has no fixed compression
   level in the registry; cai2021 m3 / m5 conditions state the 0-dB-net-gain definition (p.4), starnault2024 the 3-dB
   compression (p.3). A registry note is proposed below so the 0-dB point is not compared with compression points.
