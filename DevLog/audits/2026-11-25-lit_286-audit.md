## Coordinator questions (recommendations)

1. wang2013 granularity (judgment a). Keep one row per Table 1 design and per N: N sets the DBR length on each side of the phase
   shift, i.e. a sibling design of different length (rule 9). All 25 figure readings verified against the vector data (above);
   stated uncertainties (+/- 5 % Fig. 9, +/- 10 % Fig. 11(b)) are conservative; no value change needed.
2. wang2013 WG1 "about 40 dB" (judgment b). Keep on each of the six WG1 rows (five approx + out10 gt 40 from Fig. 7): "all the
   devices exhibit" refers to the six plotted Fig. 8 spectra, each of which shows the depth, so the value is tied to identified
   devices, not a family typical stated once (D254 does not apply). No extinction on the WG2 rows (no WG2 spectra): right.
3. wang2013 Fig. 9 "bandwidth" (judgment c). Keep `stopband_width_nm` with "level not stated": the text calls it the stop-band
   that broadens with corrugation width (p.9), no 3-dB statement exists (so bw_3db_nm is out), and about 19 merged rows use the
   same "level not stated" convention (D717, kashyap1993, tanaka2012). D82g's wording ("stopband_width_nm only for a stated
   stopband level") predates that practice; if the coordinator wants D82g read strictly, these 13 rows and the merged ones would
   need a sweep, not a batch-local change.
4. jiang2018a tuning efficiencies (judgment f). Recommend `derived` for both (patched m10): the 40 mW/nm is exactly 2 x 13^2 /
   650 W over 13 nm, i.e. the Fig. 7 measured voltages and shift; the doubling sentence explains the result. If the coordinator
   reads the doubling sentence as the source of the number, revert m10 to `author_estimate` (D256a) and keep the new note.
5. wang2013 Y-branch (judgment d). Delete (patched): the value is the topology's ideal split, no excess or other Y-branch
   performance is reported, and a 3 dB per_component IL row would mislead the splitter benchmark. Alternative if kept: change to
   `excess_loss_db` about 0 dB is not supported either (no number printed), so deletion is the only clean option.
6. Fab / facility (judgments e, f, h). wang2013 fab org_imec + org_cmc_microsystems: agree; add ePIXfab as a fab org (MPW access
   named in the fabrication sentence, Contract v7 broker rule) on all 31 remaining wang2013 rows after the org round. Centre for
   High-Throughput Phenogenomics (UBC) "for assistance with SEM imaging" (p.11): a named facility thanked for assistance, D80c
   borderline facility (characterization-facility precedents D517 / D612); recommend registering it as a facility under
   org_university_of_british_columbia and adding it to the wang2013 rows with a borderline note. jiang2018a fab empty but for
   the two-org reason (patched notes). liu2017a facility as entered.
7. Scope de_embedded for GC-normalized filter IL (patched, 3 rows): consistent with rule 6 and the merged majority. If the
