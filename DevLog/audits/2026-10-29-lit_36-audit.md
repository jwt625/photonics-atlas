## Rulings on the batch report's judgment calls

1. jiang2020 tuned zipper cavity as `resonator.photonic_crystal`: endorsed. Every measured quantity is a cavity
   property (resonance tuning, Q, linewidth; p.3-5, p.21-22); the registry def covers photonic-crystal cavities and
   `tuning_efficiency_pm_per_v` is the resonator parameter for non-thermal actuators. The nanobender is not
   characterized as a phase shifter (Fig. 5 is simulated outlook), so no second class row (D396 not triggered). AC
   coefficients with the drive frequency in condition: endorsed (Fig. 17 marker-label mapping checked: squares
   550 kHz = 25 nm/V, circles 750 kHz = 46 nm/V).
2. de2020 fab `org_globalfoundries`: kept, borderline. Unlike gentry2015 (lit_24 ruling 1: the fabrication sentence
   named only "a CMOS foundry"; IBM only in the process name), the fabrication sentence here ("fabricated in the same
   45 nm SOI platform", p.1 Sec. I) points to the platform introduced as "GlobalFoundries 45 nm SOI", which matches the
   merged precedent xu2023a "fabricated on the GF 45CLO platform". The note already says borderline. Open question 2.
3. liao2011 responsivities: author_estimate (patched), not derived; the detector power rests on the nominal 1% tap
   ratio and calculated losses (p.4), skill rule 4. Same rule applied to hu2021a (cited SSC loss).
4. lischke2021a dark currents on both rows: endorsed; p.5 states "below 200 nA at a bias of -2 V for both Ge100_10
   and Ge150_10 diodes", and the 85 C sentence continues about the same dark currents. Series resistance: the Fig. 2(f)
   range is joint (D159), replaced by the per-diode Table 1 value (patched).
5. wilmart2020 GC IL / 1-dB BW on both rows: not endorsed; the value is printed once for "the grating fiber coupler"
   (singular) while the center wavelengths are given per band; the text does not say it holds for each design ->
   D159 / D254, deleted with notes. Skill rule 7 (one value for several bands = one row) concerns one component, not
   two designs.
6. hu2021a MMI 1.1 dB as `excess_loss_db`: endorsed. The paper prints "-1.1 dB insertion loss" without a definition
   (p.2); for a 1x2 MMI whose two outputs both feed the PD, 1.1 dB cannot include the 3 dB split, so it is loss beyond
   the ideal split (skill rule 6). author_estimate, origin not stated: endorsed.
