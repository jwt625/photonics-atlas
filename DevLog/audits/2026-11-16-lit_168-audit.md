## Coordinator questions

1. liu2022d P_pi ~124 mW and response time ~47 us (p.2 Sec. II.A). Recommendation: keep both as `author_estimate` with the
   guo2021 cross-note (patched). D259 / D259a remove values the paper restates from the authors' own earlier work, and D408 limits
   that to cases where the value sentence or figure attributes the value to the earlier paper. Here the sentence carries no
   citation (the 25 kHz tuning-speed sentence a paragraph earlier on the same page carries ref. [25], so the authors do cite borrowed values), guo2021 is cited only
   in the introduction, and the P_pi differs (124 vs 122 mW; guo2021's is a simulation, liu2022d's is a different chip with a
   0.75 mm phase section and kappa2 0.052). The 47 us match and the 2.117 group index match are the weak points; they are now on
   record in the notes (D80i borderline; zhao2016 D554 / rees2020 D578 precedent). The basis keeps both out of the benchmark.
   To apply D259 strictly instead, delete m1 / m2 (the phase-shifter row keeps only `length_um`, which is geometry, so the row
   would then need deleting too under rule 9 / D49).
2. Fab. Recommendation: no op. (a) liu2022d: "The Si3N4 chip ... was fabricated in the multi-project wafer (MPW) process by
   LIGENTEC" (p.2) names the org for the Si3N4 chip only -> `org_ligentec` on the rings, phase shifter and waveguide rows
   (Contract v7 per-component fab, D515 / D463); the laser and the butt-coupling interface are assembled rows with no named
   assembler -> empty (D399, D450); identical to merged lit:chen2023 (Ligentec on dual_mrr_filter / sin_strip_wg, ECL empty).
   `process_name` "LIGENTEC MPW" is a faithful short form of the printed wording (merged forms vary: "Ligentec standard MPW",
   "LIGENTEC MPW, 800 nm SiN", "LIGENTEC AN800 MPW"; the paper prints no AN800 name, so do not add one). (b) guo2021: no
   fabrication sentence anywhere (p.5 cites ref. [51] for the heater cross-section, p.4 credits LIGENTEC with a 25 kHz result via
   ref. [3]); one co-author at LIGENTEC SA is affiliation only (D80b, Contract v7 "never fill fab from author affiliation alone")
   -> empty. If the benchmark should place guo2021 with the LIGENTEC column, that is a `family_override` / config decision, not a
   data row.
