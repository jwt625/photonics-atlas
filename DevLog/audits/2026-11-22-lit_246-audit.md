## Coordinator questions (recommendations)

1. chung2019a 10.1 kHz and 34.8 / 34.4 us (judgment a): keep. D470 removed the chung2017 50 kHz MZI-intensity value because that
   paper also printed a phase-shifter bandwidth (5 kHz) for the same device; chung2019a prints no other bandwidth and calls 10.1
   kHz the modulator's "thermo-optic modulation bandwidth" (Fig. 4(e)(f) captions, Table 1). The conditions state the null bias,
   the 0-180 deg drive and the TIA readout, and the 58.5 us phase rise (p.26) is its own measured row, so a reader can see the
   difference. The distiller's ratio check holds: for a first-order phase step read through a null-biased 0-pi MZI the intensity
   10-90 % time is about 0.62 of the phase 10-90 % time (34.8 / 58.5 = 0.59). Merged chung2017 rise / fall rows from the MZI step
   response were also kept (D470 deleted only the bandwidth).
2. chung2019a 1.23 dB (judgment b): `author_estimate` (patched). The paper never prints the conversion; it holds only with ideal
   splitting and a lossless reference arm. D80a makes model extraction `derived` only "with stated assumptions"; here they are
   unstated, so rule 4 (assumed input) applies.
3. chung2019a fab `org_tower_semiconductor` (judgment c): keep as the D84b borderline with the note. The thanks name TowerJazz staff
   for "the chip fabrication", which is the D84b case (xie2024, bhasker2026); the alias resolves (D934). No facility.
4. chung2019a U-turns (judgment d): keep `insertion_loss_db` per_component per 180-deg U-turn, not halved. Each U-turn is a six-
   segment composite (two Clothoid pairs, taper, straight), so halving into `bend_loss_db_per_90` would assign the taper and straight
   to "a 90-deg bend"; manganelli2017 (merged, per 180-deg bend as insertion_loss_db) is the precedent. Population row (D165) with
   the two per-type simulated rows is right; n_samples 5 is the printed sample count.
5. chung2019a design rows (judgment e): keep the N = 0, N = 26 and the four circular-bend rows (simulated, printed text values and
   Fig. 6(c) labels). Delete the improved type-A row (patched; see the findings table). `test_structure` true on the modulator is
   right: it is measured inside an on-chip MZI test structure on a test chip (Fig. 2(d) caption, Fig. 4(a)).
6. fujisawa2017 `soi_strip` (judgment f): keep. The paper states a Si wire 400 x 210 nm "surrounded by silica" (p.4), which is a Si
   strip on and under an oxide insulator; D422 / D423 emptied platforms only where no insulator or BOX was stated (hutchison2016,
   derose2011). Merged bend rows already use soi_strip for Si wires (26 rows).
7. fujisawa2017 slopes and simulated values (judgment g): keep. 1550 nm `wavelength_inferred` is supported by Fig. 9 (the Nb = 398
   spectra at 1550 nm give the same per-bend loss). `mean` / n_samples 10 describes the regression over the 10-chip averages.
   The Fig. 3 vs Fig. 12 / 13 values at nominal width (normal 0.024 vs 0.021, clothoid 0.0047 vs 0.0016 dB) are a real conflict
   inside the paper; noting it (D417) is right. Optional: the Fig. 12 "clothoid" curve may be a different clothoid ratio than
   clothoid-B (the paper does not say which), which would explain part of the gap; no change.
8. deng2016 (judgment h): keep one row per L, `coupling_efficiency_pct`, `reference_structure`, `measured` on the L = 4 um printed
   values (per converter of 10 cascaded, no division shown: D567), `soi_slot`. Two TE0 reads corrected and the L values made
   `extracted_from_figure` (patched).
9. novack2013 (judgment i): keep one PD row with the inductor as a condition (fard2016 precedent, D619); the once-printed 0.75 A/W and
   3 uA sit on it without a D254 issue. OpSIS confirmed missing: no row in organizations.csv and no alias in org_aliases.csv; it is
   already queued for the org round (D439, D458, D610). Add novack2013 p.5 Sec. 4 (fab role, all 17 rows) to that request.
