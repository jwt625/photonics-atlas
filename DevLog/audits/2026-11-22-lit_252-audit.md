## Coordinator questions (recommendations)

1. zhang2019g evanescent coupler (judgment a): keep it out. The result sentence (p.5) ends with ref. [31], the authors' IEEE
   Photonics Conference 2018 paper on a "wafer-scale silicon photonic interposer utilizing inverse-taper coupler", and this coupler
   is an inverse taper (250 nm tip, 500 um overlap, p.4), so the citation attributes the 0.41 dB / ~+/-3 um to that paper (D408 letter,
   D455 srinivasan2020). Weak point: Fig. 9(b) shows the data in this paper and the first-person "we fabricated ... we then performed
   an Au-to-Au flip-chip bonding" (p.4-5) describes the work. If the coordinator reads the paper as a journal extension (D408 first
   clause), the row would be `chip_chip_coupler` (SiN-to-SiN interposer, scope per_interface, 0.41 dB best, 3-dB tolerance ~+/-3 um
   from Fig. 9(b)) with facility org_marvell_nanofabrication_laboratory + org_center_for_nano_micro_manufacturing (p.8: "Interposer
   test chip fabrication took place at"; both ids exist).
2. dasmahapatra2014 classes (judgment b): keep. Matrix and element `switch_fabric.other` (D407 / D158 analogue; testa2018 / khope2019
   element rows), the fifth-order ring `resonator.coupled_rings` for FSR, kappa and tuning values (D396 cross-notes present on both
   rows). Not `wdm.mrr`: the element is a broadband spatial switch, not a channel filter in a WDM path (D400).
3. dasmahapatra2014 bases (judgment c): keep. 11.8 pm/mW and 120 mW rest on a nominal input (constant 400 Ohm, p.5; rule 4); the
   7.4 / 13.3 pm/mW and kappa are model-parameter fits (`derived`, D80a), which is a different case. Fit slope 0.9 dB and intercept
   14.0 dB `measured` (fit inside the data range, D435 / D80a). On-state 2.0 dB `author_estimate`: strict rule 3 ("values computed
   from cited values") would delete it, but the cited input is the foundry's coupler specification, the value is the paper's own
   headline (abstract, conclusion, Table II "as measured"), and D429 / D581 keep such values as `author_estimate`.
4. tanaka2009a fab (judgment d): keep empty. Device fabrication is passive with no org (p.2), "we developed" is excluded by D80b, and
   the one first-person fabrication sentence ("by fabricating two types of test waveguide samples", p.3) covers test samples that have
   no rows. If extended, org_fujitsu exists but "Fujitsu Laboratories Ltd." has no alias.
5. tanaka2009a amplifier row (judgment e): keep. Second `amplifier.soa` row for fiber-to-fiber gain and total NF (D396); gain spread as
   `il_nonuniformity_db` (max minus min fiber-to-fiber gain = IL spread; Fig. 9 confirms 1.2 / 2.8 / 3.0 dB) and PDG as `pdl_db` on
   the switch row (pdl_db is not allowed on amplifier); total NF `derived` (D80a). Conclusion 1.2 dB vs 3.0 dB stays a D417 note; 1.2 dB
   equals the TE inter-channel deviation.
6. tanaka2009a FFC (judgment f): keep 1.0 dB `author_estimate` ("exhibited" sits in a sentence that also gives a 50 um length tolerance,
   which one device cannot show; measured vs simulated not stated) and L_c 14-16 dB as an `author_estimate` loss-budget row with
   fan-outs in `includes`. Keep the Fig. 7 losses out (patched note): fiber coupling and normalization are not described, and the
   thick-core level (about 25-28 dB) sits about 10 dB above the L_c estimate the authors draw from the same passive measurements, so a
   scope-unspecified row would mislead.
7. chen2015b fab (judgment g): keep org_zhejiang_university on all rows. "We also fabricated a simple regular 14-channel AWG" (p.6)
   implies the authors fabricated the present device; p.4 adds "our fabricated SOI nanowire waveguides" and p.6 "a single MZI
   fabricated on the same chip"; all authors at Zhejiang University (D72). Weak point: the process paragraph (p.3-4) is passive.
8. chen2015b MZI (judgment h): keep both rows; the patch adds the D417 conflict note to m3 (the separately measured MZI is presumably
