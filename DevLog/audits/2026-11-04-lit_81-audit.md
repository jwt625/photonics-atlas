## Open questions for the coordinator

1. wang2016a imbalance. Recommended: D401, as patched: printed values to notes, imbalance_db holds the port difference read off the figures. gonzalezandrade2019 is not a precedent for keeping it: its p.2 defines imbalance as the power difference between outputs and no figure contradicts the +/- values; its per-port -3 +/- 0.5 dB rows were the ones D401 removed. Here the paper gives no definition, defines per-port power P / (P1 + P2) (p.6), and both figures show the +/- around -3 dB; 0.7 dB under the |P1/P2| definition understates the 1.45 dB band-edge ratio by a factor of 2. Fallback if overruled: restore 0.7 and 0.55 with the existing notes.
2. yasui2026 Q_int, Q_c, 0.526 dB/cm. Recommended: keep author_estimate (D403). The p.5 fit form is symmetric in 1/Qint and 1/Qc, so the data give the pair, not which is which; "close to critical coupling" fixes the regime only qualitatively, unlike ye2019's exactly critical resonance (D418). The ambiguity is small (7 %, in the note). q_loaded, FWHM stay measured. Re-check if Supporting Information A1 is cached: the embedded Fig. 3(a) source image shows G300 and G250 rings, so a gap series may determine the regime (lee2012 pattern, D425).
3. wu2018 class. Recommended: `resonator.photonic_crystal`. Registry subtype names Fabry-Perot cavities; p.2 describes N - 1 cascaded FP cavities and a lattice behaving like a photonic crystal; merged qi2025 FP between two Sagnac reflectors holds this subtype; merged `resonator.other` is only a coil. Not WDM: WDM is named as an application only (p.9, D400).
4. wu2018 source identity. Recommended: same work, no D397 stop, as oser2019 / wu2023 (D430) and stern2018 / qiu2026 (D433). Journal version unread, values could differ; re-check if the version of record is cached.
5. wu2018 fit alpha, 15 rows. Recommended: author_estimate as patched (rule 4; D428 sun2025 subtracted-term pattern). Fallback `derived` (D80a model extraction; merged dumon2004 racetrack loss). ng stays measured: peak positions do not depend on the level. The values themselves are unchanged.
6. Simulated values read off plots. Recommended: D80a stands, basis simulated with the uncertainty in notes (42 merged rows do this). Contract v6 says figure-read performance values are extracted_from_figure without excluding simulation; a one-line skill clarification would stop this recurring. About 13 merged lit rows (mason2025, wijk2020 and others) use extracted_from_figure on simulated curves: possible sweep.
7. wu2018 n_periods = N. Recommended: keep. p.2 calls the loops a periodic lattice, and the registry covers photonic-crystal cells. A separate n_reflectors parameter would be the alternative; it adds nothing for N-only use.
