## Open questions for the coordinator

1. jung2026 ring losses `derived` vs `author_estimate`. Recommendation: `derived` (patched, 2 ops). D76 limits `author_estimate` to an input that is not
   stated; here n_g is printed and its own row carries `author_estimate`, as merged liu2021a and ye2023 (zheng2026a also derived). The distiller read rule 4's "origin not
   stated" clause, which the skill writes for loss-budget terms. To reverse: drop the m5 / m6 ops.
2. su2017 design wavelengths and spacing. Recommendation: `simulated` (patched, 4 ops; D82a, p.4 prints the FDTD peaks at 1500 / 1540 / 1580 nm). Alternative
   `author_estimate` if the coordinator reads them as optimization targets rather than computed results; `design_target` contradicts D82a either way.
3. su2017 platform `soi_strip`. Recommendation: accept (lit_69 convention: the paper names the full etch). Sibling piggott2015 stays `soi` in the merged table, a
   candidate for the open soi sweep. To reverse: drop the component op.
4. su2017 figure-read 3-dB widths (3 rows). Recommendation: accept (D456 precedent; the passband width is the main metric of a narrowband demultiplexer). The S31
   value describes a slow edge rather than a passband; drop m26 alone if that row is judged misleading.
5. jung2026 3-dB bandwidth `gt` 900 nm `author_estimate`. Recommendation: keep. The printed bound needs an upper edge beyond the 1730 nm data end (850 to 1740 /
   1750 nm), so it is not a fit inside the data (D435); Fig. 3(c) supports more than about 880-900 nm depending on where the lower edge is read. Alternative: delete.
6. hsu2023 single-ring row class `wdm.mrr`. Recommendation: keep (Fig. 5(b) caption calls the individual ring part of the filters; D400), with the identity
   caveat now in notes. If the coordinator reads the Fig. 2 ring as a stand-alone test ring, reclass to `resonator.ring` (tuning_efficiency_pm_per_v,
   tuning_range_nm, q_loaded, extinction_db and width_nm are all allowed there).
7. Registry extension and org round: the items above.
