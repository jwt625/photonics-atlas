## Coordinator questions (recommendations)

1. CPW electrode RF loss (<= 0.5 dB cm-1 GHz-0.5, >= 15 um thick plated electrodes, wooten2000 p.4). Keep out. Recommended
   reason in this order: (a) rule 2: electrode RF loss is a modulator quantity with its own EO atlas columns
   (`rf_loss_db_per_cm`, `rf_loss_freq_ghz`); (b) it is a generic "in general" bound for a class of electrodes, not a
   result of a device (no device, length, frequency or measurement); (c) no component class or parameter exists for RF
   electrodes, and none should be proposed from a single generic bound (D250 "never add a parameter without a value" spirit).
   The distiller's reading of the value from the render is correct (the text layer drops "15" and "0.5").
2. CATV linearizer coupling-angle tolerance (2 %, i.e. 4 deg, wooten2000 p.9). Keep out. It is a requirement on the
   relative coupling of two directional couplers inside a modulator, phrased as what the device "requires", with no
   achieved value; it would fail rule 9 (no performance metric) and rule 4 (no basis fits a requirement). If ever
   recorded, only as a note on an EO atlas row, not here.
3. Whole-batch outcome. Accept 0 / 0 for both papers; no further action.
