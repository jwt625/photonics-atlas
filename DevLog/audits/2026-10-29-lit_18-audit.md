## Rulings on the batch report's judgment calls

- cheung2022 10.0 nW (p.4 [16]): removed (see table). D259a strict: the number sits in a sentence citing the authors'
  own earlier MOSCAP (de-)interleaver paper and this paper shows no own current measurement; abstract (p.1) and
  conclusion (p.7) restatements do not make it an own result. The Fig. 5(c)/(d) XT values (-7.3 / -10.7 / -16.4 /
  -26.6 dB) stay: the figure and its sentences carry no citation and are presented as measured (p.4).
- cheung2022 MOSCAP MZI and microring modulator left out: endorsed (skill rule 2; MOS / plasma-dispersion phase
  shifters are EO-atlas scope, e.g. akazawa2026 hybrid MOS phase shifter in `devices.csv`). Their passive values map
  to EO-row columns (MZI FSR 17.9 / 19.0 nm -> fsr_nm, ER ~24 / ~30 dB -> extinction_ratio_db, ring Q 8250 ->
  q_loaded, round-trip loss 13 cm-1 -> prop_loss). The two values without an EO column, ring power coupling 0.0494
  (p.5) and resonance drift ~73.6 pm/C (p.5), go with the EO-atlas candidate: under rule 2 they are entered as a
  resonator row hosted by the EO device row once cheung2022 is in the EO atlas (a host-less row now would duplicate
  that later). MZI leakage "sub-nA" has no parameter.
- cheung2022 fab empty: endorsed (D80b; passive "fabricated", "past in-house fabrication" p.7 refers to the budget).
  Interleaver-chip GC ~22 dB as author_estimate / scope unspecified: endorsed (p.5 "estimated", one vs two GCs not
  stated). SOA gains [24] and BER [14] not entered: endorsed (cited). Table III budget not entered: endorsed.
- cheung2022 45 deg interface reflection < -60 dB not entered: endorsed (simulated only; gap listed, low priority).
- huang2019 DBR lasers as laser.heterogeneous with tag dbr: endorsed. The heterogeneous subtype records the
  integration route (bonded III-V on Si); the merged III-V-on-SOI laser with a Si DBR mirror (keyvaninia2013) is
  laser.heterogeneous, and the only laser.dbr row (ofc2026 w2a2) is a hybrid InP/polymer laser; the cavity type sits in
  the tag, as for the merged rows.
- huang2019 ULL loss 0.16 / 0.04 dB/cm, ring Q 4.1 M / 2.1 M, bend radius 600 um (Table 1 [28]): endorsed as cited
  ("previously demonstrated", p.2). Lasing ~1562.7 nm not entered: endorsed (design not identified, D159). Fab empty:
  endorsed (passive, p.4 Sec. 3). Facet 6.5 dB as measured per_facet: endorsed (D167, stated without arithmetic).
- ramirez2022: 22 mW / WPE 17 % as author_estimate (waveguide-coupled, GC calibration not described): endorsed.
  13.4 dBm duplicate, D factor, lifetimes (abstract 8 ps vs text ~18 ps), large-signal ER: endorsed. T0 / Zth C -> K
  relabel as derived: endorsed (D256). Fab empty: endorsed ("were fabricated using a backside processing", passive).
- tanaka2012: Si-SOA 1.55 dB as author_estimate per_interface: endorsed (p.9 / Table 1: subtraction with an assumed
  0.6 dB waveguide loss). 25 mA / 10.5 mW temperature implied: endorsed with temperature_k empty and the note. Mirror
  3.5 dB (simulation input), mirror 3-dB width ~0.3 nm (ring + DBR, no single row), RR drift 0.076 nm/C ([15]),
  output-coupler 2.6 dB (out-coupled fraction): endorsed. DBR "stopband ... 5.6-nm wide" kept as stopband_width_nm
  with "level not stated" (the paper calls it stopband; D82g reserves bw_3db_nm for a stated 3-dB band). Fab empty:
  kept (see question 1). Ring class changed (table).
- winkler2024: Si3N4 loss 0.32 dB/cm from [10] (authors' own earlier paper) not entered: endorsed (D259). EXALOS AG
  needs no registry row now: the purchased gain chip is a part of the laser, not the device under test (rule 12 vendor
  clause), and no gain-chip row exists. Fab empty: endorsed (FIB "we create" by authors at four orgs, D72 / D83c).

  "grown by MOVPE at the National Epitaxy Facility, Sheffield", i.e. the growth step of this work was performed at a

  Not set on the GOS rows or the end-fire interface. Platform `inp` removed (table). Coupling values as

- morenopozas2025 class: changed to mode_converter.converter. The device converts the guided TE0 mode of a 0.5 um wire
  into the guided TE0 mode of a 285 um waveguide in the same 220 nm layer, IL defined on the fundamental modes (p.1,
