   ("Sandia National Labs' radiation hardened six inch ... 0.35um process using 248nm lithography"), the Contract v7 "named

   made in the authors' "fabrication facility (fab) runs" with the process of ref. [14]. `process_name` as printed is fine.
   No facility named (the acknowledgment is the operator statement only).
2. zortman2010 GHz / THz spreads as `wavelength_spread_nm` `derived` (judgment a). **Keep.** D256 covers any unit
   conversion as `derived` with the printed value in notes, and D633 accepted the same frequency-to-wavelength conversion
   (zhou2023a 59 GHz -> 0.462 nm, lambda^2 df / c). The parameter definition (spread across chips or channels, kind in
   condition) fits all twelve rows, including |W1-W2| as a wafer-to-wafer spread. First-order conversion error is below 0.7 %
   even for the 2.5 THz range (df / f = 1.3 %), well under the printed precision. Each row names its conversion frequency;
   if a `frequency_spread_ghz` parameter is created later (registry gap 1), re-point these rows mechanically from the notes.
   105 GHz / 70 GHz `derived` (model reconstruction with stated assumptions, D80a) also kept; an `author_estimate` reading
   (rests on simulated sensitivities and the removal of a hypothesized mask error) is the alternative if the coordinator
   prefers to flag "process capability" values.
