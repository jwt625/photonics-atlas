   the registry definition is the tooth (unetched) fraction and requires converting a groove-fraction definition (1 - f,
   `derived`, printed values and definition in notes), which the rows do; no change. (d) Uniform reference 3.4 dB: keep as
   `extracted_from_figure` with the +/- 0.4 dB fringe band; scope `loopback_half` is the only reading consistent with the
   paper's single measurement description. (e) Fab empty (passive sentence, D80b). Cross-note for the record: bozzola2015 (p.4)
   quotes this paper as 74 % (-1.31 dB) experimental; chen2010 itself prints 1.2 dB / 75.8 %, which is what is entered.
2. laere2007 judgment calls. Recommendation: keep. (a) 69 % `per_coupler` / `reference_structure` / `measured`: the divisor is
   the paper's own 26 % reference value, the fit is of own data (D80a), and no arithmetic is shown (D167); `author_estimate`
   would apply only if the divisor were assumed or cited. (b) Unbonded regular SOI row `design` (simulated only; the measured die

   DUV process detail points only to ref. [14]).

   rows are right (rule 9). (b) Tolerance statements (p.12) name "the un-constrained apodized design in 340 nm SOI" while two
