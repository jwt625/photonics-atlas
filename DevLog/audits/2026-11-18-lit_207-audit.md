## Coordinator questions (recommendations)

1. Scope (judgment (a)). Recommendation: keep. The part is a planar printed-polymer splitter on a printed substrate, the same
   group, material system, 30 mm length and setup class as the merged `cmp_lit_moralesalvarado2026_y_branch_5pct`, which D428
   kept under D411; dropping this one alone would split one device family. It is not a bulk crystal part. If the coordinator ever
   narrows D411 to exclude mm-core free-space-coupled printed guides, both papers go together.
2. Excess loss scope (judgment (b)). Recommendation: keep `device_total` / `measured` with the per-sample values and the
   EL definition in notes. EL here is Pin / (P_left + P_right), so it carries free-space input coupling, both face reflections,
   propagation and junction scattering; nothing is de-embedded. `per_component` would be wrong.
3. Imbalance (judgment (c)). Recommendation: keep the derived range 0.27-0.60 dB. D401 does not apply: Table I gives each
   port relative to the summed output (the two ports sum to 100 % within rounding), not a "3 +/- x dB" transmission relative to
   the input, so the left-right difference is a port ratio. The printed 0.6 dB worst case stays in notes (equal to the maximum).
4. split_ratio_pct (judgment (d)). Recommendation: keep both per-port rows, `derived` (D256: % not printed; the conclusion's
   "50 % to 50 %" is qualitative), with the port now named in the condition (patched).
5. Arm width (judgment (e)). Recommendation: enter 1.00 mm from the Fig. 2 label (patched), not the 800 um of the RSoft model.
   The distiller already took length from the printed device (30 mm) rather than the 33 mm simulation model; the width should come
   from the same printed-device model. Fig. 2 is that model (p.2 Sec. III), its 1.00 dimension is drawn on one output arm's edges,
   and the p.3 "about 1 mm" input-guide diameter agrees; D156 does not apply (the label is tied unambiguously by extension
   lines). Basis `derived` (rescaled label, D157), consistent with m6 which also rests on Fig. 2. Revert = drop the m7 op and the
   component notes op. Geometry rescale rows (m5, m6, m7) `derived`: agreed (D157).
