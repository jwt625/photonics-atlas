## Coordinator questions (recommendations)

1. chang2018b fab HUST on the MUX / DEMUX row: keep. p.5 describes one fabrication flow (EBL, ICP, 1.2 um SiO2) for the device and
   says the reference MDM system "was also fabricated"; p.7 adds the first-person "we also designed, fabricated and experimentally
   characterized" for the cascades; all seven authors HUST. Same construction as zhang2022c (D656: one monolithic flow, fab on all
   rows).
2. chang2018b p.4 Y-junction geometry on the MUX / DEMUX row: keep with the caveat note. The crossing's converter and the reference MUX
   carry the same name ("SW structure asymmetric Y-junction", p.4 / p.5), both point to ref. [23], and the 30 x 40 pixel count of
   120 nm reproduces the printed 3.6 x 4.8 um2. The geometry is design (design_target / derived), not a value whose sample identity
   matters (D159 not triggered). The Fig. 4(b)-(c) SEMs of the converter and the DEMUX show similar-looking pixel blocks at render resolution (not proof of
   identity, hence the note).
3. Back-to-back reference systems (chang2018b MUX + DEMUX, liu2023b PSR pair) scope `unspecified`: keep. Neither paper states what
   these spectra are normalized to (chang2018b Fig. 3(c)-(e) wanted ports sit near 0 / -1 / -1.5 dB, liu2023b I1 < 0.4 dB, so the
   grating couplers are evidently removed somehow, but the reference is not named). `de_embedded` asserts a stated coupler removal
   (a2017 had one); `includes` already names the two-component path.
4. chang2018b abstract 0.9 dB / -24 dB: keep out with the component note. The body's own cutback (1.42 / 1.92 dB per crossing for TE1 /
   TE2, p.7), the p.3 introduction (< 2 dB, < -20 dB) and the conclusion (p.8) all contradict "< 0.9 dB for all the three modes";
   D535 (liu2019 headline NF left out) fits. D417 (tossoun2024) kept a value the paper uses in its own arithmetic, which is not the
   case here.
5. chang2018b "< 2 dB" single-device row scope / method `unspecified`: keep. The paper says "normalized" (p.7) and that the reference
   MDM system was fabricated "to evaluate the performance of the device" (p.5), and the Fig. 5(d)-(f) fit lines extrapolate to near
   0 dB at zero crossings, all consistent with normalization to the reference system, but the reference of the normalized spectra
   is never named (rule 6: unspecified, never a guess). The isolated per-crossing values are already on m1-m3 (cutback).
6. zhang2013b: keep C band inferred (rule 8: no wavelength stated with the values; peak-fit values with Fig. 3 peaks near 1535-1540 nm,
   design wavelength 1550 nm, scan 1500-1580 nm). Keep fab empty: "the foundry" whose DRC was used is not named and the
   fabrication sentence is passive (Contract v7, D433); IME co-authorship is affiliation only (D80b). Keep the 26-die mean / std /
   range rows (printed mean +/- std and bounds; statistic std allowed, D81; n_samples 26).
7. sanchis2007: do not add 50 / 70 / 110 / 130 deg as design rows. They are 3D-FDTD points of an angle sweep with no device and no
   design the paper puts forward (its design result is the 60 / 120 deg optimum, which is fabricated and entered); four design rows
   with three simulated values each would add sweep samples, not components. Keep 1.6 dB on both 60 and 120 deg rows (the conclusion
   sentence names both angles; Fig. 3 reads 1.61 / about 1.62 dB). Keep 3D-FDTD figure reads `simulated` (D454) and the
   experimental reads `extracted_from_figure`; values confirmed by pixel reads (above).
8. celo2014: keep fab `org_cmc_microsystems` alone. "through a CMC (Canadian Microelectronics Corporation) Microsystems
   multi-project-wafer run" (p.2) names the MPW access provider for the fabrication (Contract v7, D83d, D398); the foundry is only
   "a silicon photonics research foundry" (p.1), so no foundry org can be entered (D433). Keep 9.9 dB as `fiber_to_fiber` loopback
