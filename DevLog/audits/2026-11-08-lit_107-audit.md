   MQWs (only grown on InP in practice) and trappen2020 names the standard imec silicon photonics platform, but neither prints InP / SOI / a BOX.
   Recommendation: accept the patch (empty platform, D422 / D423, Contract v7: distillers never default a platform; the benchmark places such
   rows with `family_override`). To keep the defaults, drop the `platform` field of the 3 component ops (the notes then need their last
   sentence removed).
2. luquegonzalez2019 class (batch judgment call 11). Merged practice is split: width tapers (dumon2004, dostart2020, papadovasilakis2023a,
   lu2025a, ...) are `waveguide_platform.other`, while the same group's parabolic-reflector spot-size converter morenopozas2025 is
   `mode_converter.converter` (with `bw_1db_nm` > 380 nm). Recommendation: keep `waveguide_platform.other` here (no mode-order change; the
   `subwavelength_period_nm` row is not allowed on mode_converter), and list morenopozas2025 for a later SSC class sweep. If mode_converter is
   preferred, the 240 nm SWG period row moves to notes and a `bw_1db_nm` 130 nm (gt, setup-limited, p.4 Sec. 4) row can be added.
3. trappen2020 probes in scope as components (batch judgment call 9). Recommendation: keep (paper subject, fiber-attached passive parts,
   D411; D160 targets setup equipment entered as a component, as djogo2026).
4. guzman2017 m12 272 ps electrical pulse width on a 2 GHz oscilloscope. Recommendation: keep with the condition (ibrahimi2021 m4 precedent);
   it is not an optical autocorrelation width, so views that rank optical pulse widths should filter on the condition.
5. guzman2017 m2 hybrid repetition rate = RF drive setting. Recommendation: keep as measured (the locked tone is shown at that frequency,
   Fig. 4(a), (b); wang2025a precedent).
