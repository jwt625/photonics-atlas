## Coordinator questions

1. catalalahoz2026 Vpi, rise / fall, ER and non-volatile phase rows vs rule 2 (distiller call). The values are modulator-type
   metrics, but catalalahoz2026 is not an EO-atlas source (no `catala` / host row in `../eo-modulator-atlas/data/devices.csv`),
   so there is no EO row to duplicate; `v_pi_v`, `rise_time_us`, `extinction_db` are registry phase_shifter parameters and
   merged lit phase shifters carry them (shu2026 D589, poulton2019 D582). Recommendation: keep on the phase-shifter row (no
   op) and list catalalahoz2026 as an EO-atlas candidate (BTO Pockels / ferroelectric phase shifter with Vpi, 82 ns switching).
   If the EO atlas later ingests it, rule 2 moves Vpi / rise / fall / volatile ER there and fills `host_device_ids`.
2. Platform `bto_on_si` on the NV-PUC, mesh and configured-filter rows. Each PUC is 950 um with two 350 um Si-BTO arms and
   Si-to-Si-BTO tapers (p.5, p.11); every mesh path, ring and UMZI traverses those sections, and the 1.48 dB PUC loss is
   attributed to the tapers (p.10). Recommendation: keep `bto_on_si` there and `soi` on the grating couplers (no op). The
   mesh row's Si SEM geometry (512.6 x 242.5 nm) describes the Si core of that hybrid stack; switch_fabric has no layout
   template, so no drawing reads it as a BTO film. Alternative if views should place the passive mesh with Si: `soi` on the
   five configured filter rows only (they report only FSR, set by path length).
3. catalalahoz2026 fab `org_cea_leti` + `org_lumiphase`. p.11 "200 mm base wafers ... were fabricated at CEA-Leti", then
   "transferred to Lumiphase, which transfers the BTO layer"; p.12 contributions name the CEA-Leti authors for Si wafer
   fabrication and planarization and the Lumiphase authors for BTO integration. Recommendation: keep both on the BTO rows and
   CEA-Leti alone on the grating couplers (Contract v7 per-part fab, D515 / D463); no `process_name` printed. The final
   cladding / metallization step names no org (notes say so). For the foundry benchmark these rows are hybrid post-processed
   parts; the coordinator may list them in `exclude_values` if the CEA-Leti column should hold Si passives only (D933).
4. vagionas2021 net gain basis. Recommendation: `author_estimate` on m1 / m2 (patched). The paper's own method sentence
   (p.5) computes net gain from the coupling losses, and 3.6 dB is reproduced exactly only by -27.4 + 18.8 + 12.2 with the
   estimated terms; D166 (`derived`) requires own measured losses. To keep `derived`: drop the two ops (header).
5. ning2022 fab `org_amf`. p.3 "by utilizing the silicon photonics multi-project wafer (MPW) service of Advanced Micro Foundry
   (AMF)" names the foundry with the fabrication (D398, Contract v7). Recommendation: keep on all 10 rows; `process_name`
   empty ("standard processing flow provided by foundry", p.4, is generic, not a named PDK).
6. ning2022 Fig. 8 low-kappa reads. The distiller read only kappa = 0.5, citing overlap; the red dashed kappa = 0.29 curve is
   clear (0.11-0.22). Recommendation: keep the added dc_k029 m5; leave kappa 0.2 / 0.08 / 0.04 out (they overlap within
   0.01-0.15 at render resolution, D156). To drop the read: remove that add and the dc_k029 note op (header).
